# Manage Feature

## 统一自选基金，大盘指数和环球指数的管理界面
* 取消主界面上，自选基金的删除按钮及相关代码。即不支持主界面上直接删除单个基金的功能。
* 点击管理按钮后，进入到管理模式后，所有自选基金，大盘指数和环球指数都统一在card右上角显示删除多选按钮。默认不选中，点击按钮后变为选中。
* 目前的退出按钮改为确认按钮，旁边增加取消按钮。点击确认按钮后，删除所有选中的基金，大盘指数和环球指数，然后退出管理模式。点击取消按钮后，退出管理模式，不进行任何删除操作。
* 管理模式界面上的“批量管理“文字，改为”批量删除“。
* 删除多选按钮的位置参照目前指数card的删除按钮位置，形式为radio button，选中后的效果是一个红色的叉叉，与目前界面上的删除按钮类似。
* 若没有配置任何基金或指数，则管理按钮不可用。
* 管理模式下，当选中card上的radio button时，在“批量删除”文字和“确认”按钮的中间显示“n个项目待删除“，其中n为选中的card数。当选中的card数为0时，不显示任何文字。
