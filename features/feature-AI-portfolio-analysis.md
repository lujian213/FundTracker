# AI Portfolio Analysis Feature

## AI投资组合分析
AI投资组合分析可以利用AI对用户的投资组合进行分析和评估，提供投资建议和风险提示。这个功能可以帮助用户更好地了解自己的投资组合的表现和风险，并提供一些有价值的建议来优化投资组合。

### 界面入口
* 在基金持仓窗口的放大镜图标旁边增加一个“AI分析”图标，点击打开AI分析浮窗。

### AI分析浮窗
浮窗中用html显示AI分析的结果。此浮窗没有输入框，用户只能在这个窗口里查看AI分析的结果。
* 如果用户没有配置好AI模型，或者没有激活的AI模型，窗口里会显示提示信息，引导用户去AI配置窗口进行配置和激活。
* 打开窗口时，自动使用预先配置好的提示词模板，向AI模型发送请求，
* 窗口设有滚动条，用户可以滚动查看AI分析的结果。
* 窗口右上方有一个叉叉按钮，用户点击后可以关闭这个窗口。
* 等待AI分析结果的过程中，窗口里会显示一个加载动画，提示AI正在分析中。
* 如果API调用失败，窗口里会显示错误信息，并提供一个重试按钮，用户点击后会重新发送请求。

#### 实现细节
##### AI模型调用
AI模型调用的实现细节可以参考AI助手里的AI配置参数获取，大模型调用的方式。
##### 提示词模板
提示词模板放在一个配置文件中。方便将来的修改和扩展。模板中可以使用一些预定义好的变量：包括
  * portfolio:投资组合，本身是一个列表，包含了很多个fundItem
    * fundItem:代表每一个持仓基金，包含了以下字段：
      * code:基金代码
      * name:基金名称
      * position:持仓份额
      * marketValue：持仓市值
      * ratio：持仓占比
      * avgCostPrice：平均成本价

这些信息都可在基金持仓界面的表格内获取到。

模板使用这些变量来构造提示词，向AI模型发送请求。比如：

```text
请你帮我分析一下我的投资组合，给出一些优化建议。以下是我的投资组合的详细信息：
{portfolio}
请你结合当前的市场环境和投资趋势，给我一些分析和建议。
```
