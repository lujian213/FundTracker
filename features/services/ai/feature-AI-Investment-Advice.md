# 投资计划AI辅助

投资计划AI辅助可以根据用户的基金持仓情况，以及基金本身的基本信息，自动制定今天的一揽子投资计划（基金）。

## 界面入口
* 在投资计划草稿窗口的工具栏上增加一个"AI辅助"图标（可以选择copilot相关的驾驶员图标），点击后将进行AI辅助决策后的投资计划自动填充到下方的表格中。
* 下方表格中，第一列多选按钮后面增加一列（用"提示列"来指代它），不显示列名，在每行预留一个图标的位置。默认不显示。重置按钮在点击时，除了原有重置功能外，还应该重置提示列（清空）。

## 界面效果
* 在点击按钮之后，如果此时表格里面有用户输入的数据，那么在开始辅助决策之前，弹出警告对话框，警告用户所有数据将会被清空。用户可以选择继续或放弃（放弃操作，终止流程）。
* 用户确认后填充之前，先对表格原有填充数据清空，恢复初始状态。
* AI辅助决策返回后，弹出对话框，通知用户辅助决策已经完成，并且展示AI辅助决策的结束摘要。用户点击确认后，关闭对话框，并且将AI辅助决策返回的投资计划填充到表格中。
* 填充时，将AI辅助决策返回的投资项目填充到对应的基金投资行上。每条有投资决策的行的"提示列"显示一个提示图标（小的蓝色感叹号）。图标上可以展示AI辅助决策的理由以及得分。同时，注释框里面自动填充当时的涨跌幅。
* 

## 运算逻辑
* 数据来源：与"投资计划AI助手"的数据来源类似，除了下面的区别。
  * 不需要用户今天的投资计划数据，因为这是我们的输出。
  * 基金的信息的范围是所有在表格上显示的所有基金。
* 使用提示词模板1，向AI模型发送请求，获取投资计划的建议。
* 收到AI模型返回的结果invest_list后，将原始问题和AI模型的回答作为上下文，使用提示词模板2，接着续向AI模型发送请求，要求得到对invest_list的每条投资计划的合理性得分后的结果（invest_with_score_list）。
* 如果所有投资计划的合理性得分都高于某个阈值（例如0.7），则计算结束。否则继续在上下文中加入AI模型的合理性分析的反馈，继续使用提示词模板3向AI模型发送请求，要求它对invest_list进行修改优化，得到新的invest_list，如此循环，直到得到的invest_with_score_list中所有投资计划的合理性得分都高于某个阈值（例如0.7，结束摘要：“辅助决策成功”），或者达到最大迭代次数（例如3轮）为止（结束摘要：“辅助决策部分成功，达到最大尝试轮数”）。
* 示例流程：
  * 第一次请求：用户点击AI辅助按钮，发送提示词模板1，得到投资计划建议列表invest_list。
  * 第二次请求：将第一次请求的内容和invest_list形成上下文和提示词模板2的请求一起发送给AI模型，得到每条投资计划的合理性得分列表invest_with_score_list。此为第一轮。
  * 如果invest_with_score_list里面有得分低于0.7的，则将invest_with_score_list加入上下文，使用提示词模板2，一起发送给AI模型，要求它对invest_with_score_list进行修改优化，得到新的invest_list。
  * 第三次请求：将新的invest_list加入上下文，和提示词模板3的请求一起发送给AI模型，得到新的invest_with_score_list。此为第二轮。
  * 如果新的invest_with_score_list里面所有得分都高于0.7，则计算结束。否则继续进行第三轮请求，直到达到最大迭代次数为止。

### 加载状态
* 点击AI辅助按钮后，按钮图标开始旋转动画，表示正在加载
* 加载过程中，所有交互元素（按钮、表格输入）均被禁用，防止用户操作
* 整个界面添加透明遮罩层，视觉上提示用户等待
* AI返回结果后，旋转动画停止，交互恢复正常

### 注释字段填充
* 表格填充时，注释字段自动填充当时的涨跌幅
* 格式：正数显示为"+X.XX%"，负数显示为"-X.XX%"
* 示例："+2.35%" 或 "-1.20%"

### 实现细节
#### AI模型调用
AI模型调用的实现细节可以参考AI助手里的AI配置参数获取，大模型调用的方式。如果调用失败，弹出对话框，通知用户调用失败，并且显示具体失败信息，例如AI没有正确配置，引导用户去系统设置里面进行配置。

#### 提示词模板
提示词模板放在一个配置文件中。方便将来的修改和扩展。模板中可以使用一些预定义好的变量：包括
  * json_content: Json格式的结构化数据，和"投资计划AI助手"里面的json_content类似，除了下面的区别。
    * 没有用户输入的投资计划数据（包括今日计划操作，操作份额，估算金额），因为这是我们的输出。
  * json_schema: Json格式的结构化数据的schema说明，告诉AI模型json_content里面包含了哪些字段，代表什么含义，帮助AI模型更好地理解json_content里面的数据。
    * 基金信息的nav_last_10_days，ma5_last_10_days，ma10_last_10_days，ma20_last_10_days要明确指明从最近数据开始。
    * 指数信息values_last_10_days，volume_last_10_days，ma5_last_10_days，ma10_last_10_days，ma20_last_10_days要明确指明从最近数据开始。
模板使用这些变量来构造提示词，向AI模型发送请求。

* 提示词模板1
````markdown
你是一名资深基金投资顾问，拥有丰富的投资经验和敏锐的市场洞察力。
以下是我的持仓结构化数据（JSON格式），请自行联网搜索获取的今日及近期重大财经新闻、宏观事件，制定我今天的基金投资计划。

输出：纯json格式的结构化数据（不要嵌套在```json```代码块里），包含需要交易的每个基金的代码，操作（买入/卖出），金额（元），解释。下面是示例：

    "fund_code": "000001",
    "operation": "buy",
    "amount": 1000,
    "reason": "根据今日的财经新闻，预计该基金的投资标的公司将会有利好消息发布，短期内股价有上涨潜力。"

  {
    "fund_code": "000002",
    "operation": "sell",
    "amount": 500,
    "reason": "根据今日的财经新闻，预计该基金的投资标的公司将会有利空消息发布，短期内股价有下跌风险。"
  }
]
```
````
