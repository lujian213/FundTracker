# Export and Import Feature

为系统增加导出和导入的功能，允许用户将当前必要的用户信息保存到本地文件中，并且能够从本地文件中导入数据。这样用户可以在不同设备之间迁移数据，或者在需要时备份和恢复数据。
## Export
* 导出的数据包含：
  * 基金基本信息：基金代码，基金名称（optional），最近确认净值（optional），最近确认净值时间（optional），最新估值（optional），最新估值时间（optional）
  * 大盘指数和全球市场信息：指数代码，指数名称（optional），最近行情（optional），最近行情时间（optional）
  * 基金仓位配置信息：基金代码，满仓额度，初始持仓，初始价格（optional），起始日期，初始价格（optional）
  * 基金所有交易信息：基金代码，交易日期，交易类型，交易份额，价格（optional），手续费
  * 配置信息：每日自动导出时间
* 导出分为人工导出和自动导出
  * 人工导出：通过在顶部菜单栏点击“导出备份”触发，导出格式为JSON文件，文件名形式为“fund_backup_yyyy-MM-dd_HH-mm-ss.json”,其中yyyy-MM-dd_HH-mm-ss为本地时间戳，例如fund_backup_2026-02-27_13-05-04.json
  * 自动导出：系统每天根据自动导出时间的配置（见config）定时触发，导出格式为JSON文件，文件名形式为“fund_backup_auto_yyyy-MM-dd.json”,其中yyyy-MM-dd为本地当天日期，例如fund_backup_auto_2026-02-27.json。
自动导出发生前5秒时，在主界面上部，显示“正在自动备份数据...”的文字，浅绿色的底色，备份结束后,显示“备份成功”，3秒后，文字消失。备份过程，不需要用户确认，可以做到全自动化进行。
## Import
* 导入数据：
  * 基金基本信息：optional的信息是作为fallback使用的，不一定准确。系统优先从数据缓存根据基金代码进行获取。如果数据缓存还没有准备好，则取用optional的信息，方便界面秒开和有数据显示。
  * 大盘指数和全球市场信息：optional的信息是作为fallback使用的，不一定准确。系统优先从数据缓存根据指数代码进行获取。如果数据缓存还没有准备好，则取用optional的信息，方便界面秒开和有数据显示。
  * 基金仓位配置信息：optional的信息是作为fallback使用的，不一定准确。系统优先从数据缓存根据基金代码和起始日期获取该日净值作为初始价格。如果数据缓存还没有准备好，则取用optional的信息，方便界面秒开和有数据显示。
  * 基金所有交易信息：optional的信息是作为fallback使用的，不一定准确。系统优先从数据缓存根据基金代码和交易日期获取该日净值作为交易价格。如果数据缓存还没有准备好，则取用optional的信息，方便界面秒开和有数据显示。
  * 配置信息：若没有该信息，则取用默认值
  * 所有optional的数据最终都应该被数据缓存里的信息取代，以保证下次导出的时候，数据是最新的，准确的。
* 导入行为：
  * 数据导入生效前，应该弹出确认框，给出数据覆盖警告。
  * 导入动作将完全抹除原有的基金，大盘指数，全球市场信息，以及基金仓位配置和交易信息，由新的数据替代。
## Config
在顶部菜单栏，增加“备份设置”菜单项。点击后打开“备份设置窗口”，可以配置每日自动导出的时间，默认值为每日local时间下午4点。在下方显示还有多长时间触发下一次自动导出。
## Compatibility
新的导入功能，必须兼容原有导出的数据文件。不会出现无法导入或导入后关键数据缺失的情况。
