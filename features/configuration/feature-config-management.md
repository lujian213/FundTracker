# Config Management Feature

将目前系统中所有配置相关的功能进行整合和规范化管理。

## 界面入口
在主界面，将右上角的下拉菜单，改为系统配置图标按钮，点击后进入系统配置界面。

## 系统配置界面
系统配置界面左侧为配置功能导航栏，右侧为配置内容展示区。配置功能导航栏包含以下选项：
* 备份管理
* 同步管理
* AI配置
* 系统开关
* 系统参数
* 交易策略
* 搜索服务
* 依赖服务
* 系统资源
* 数据快照

### 备份管理
分为2个section：
* 自动备份: 将现有备份设置功能整合进来。
* 手动备份： 提供"导出备份"和"导入备份"两个按钮，对应目前的导出备份和导入备份功能。

### 同步管理
将现有的同步设置功能整合进来，在测试连接按钮旁边提供"立即同步"按钮，用户点击后可以立即进行数据同步。

详细的同步配置管理需求请参见 [同步功能需求文档](feature-sync-with-eggfund.md#1-同步配置管理)。

### AI配置
将现有的AI配置功能整合进来，用户可以在该页面进行AI相关的设置和调整。

### 系统开关
将现有的系统开关功能整合进来，用户可以在该页面进行系统功能的启用和禁用设置。开关状态即时生效，并且在localStorage中进行持久化存储，以便在用户刷新页面后仍然保持之前的开关状态。界面要为以后可能增加的其他系统开关预留空间，设计上要考虑到未来可能会有多个系统开关的情况。每个开关包含标签、描述和开关状态文字（"开启"/"关闭"）。
#### 初始价格调整
用户可以通过开关组件来控制初始价格调整功能的开启和关闭。当开关处于关闭状态时，用户无法在基金详情页上看到"调整初始价格"的扳手图标按钮，也无法通过其他方式进入初始价格调整窗口。当开关处于开启状态时，用户可以在基金详情页上看到"调整初始价格"的扳手图标按钮，并且可以通过点击扳手图标按钮进入初始价格调整窗口。默认为关闭状态。
#### 后台任务日志
用户可以通过开关组件来控制后台任务日志窗口按钮的可见性。当开关处于关闭状态时，用户无法在主界面右上角看到日志按钮，也无法通过其他方式进入后台任务日志窗口。当开关处于开启状态时，用户可以在主界面上看到"日志"的按钮，并且可以通过点击该按钮进入后台任务日志窗口。默认为关闭状态。
#### OCR调试面板
用户可以通过开关组件来控制OCR调试面板按钮的可见性。当开关处于关闭状态时，用户无法在OCR相关功能的结果窗口看到OCR调试按钮，也无法通过其他方式进入OCR调试面板。当开关处于开启状态时，用户可以在OCR相关功能的结果窗口看到OCR调试按钮，并且可以通过点击该按钮进入OCR调试面板。默认为关闭状态。

### 系统参数
提供系统运行参数的配置功能。

#### OCR并发数量
用户可以通过滑块控件调整OCR处理图片的并发数量，范围为1-8，默认为3。并发数量越高，处理速度越快，但资源占用也会增加。参数调整实时生效，无需点击保存按钮。

### 交易策略
用户可以在此页面自定义各交易策略的参数值。界面根据系统中注册的策略动态生成配置项，新增策略无需修改UI代码。

#### 界面结构
页面顶部显示提示信息，说明参数填写方式。下方为策略折叠卡片列表，每个策略可展开/折叠。展开后显示该策略的所有参数配置项。

#### 参数配置项
每个参数配置项显示：
* 参数名称（英文key）
* 参数类型（number/string/bool）
* 参数描述
* 输入组件

对于不同类型的参数：
* **number类型**：文本输入框，可填写数字或表达式 `${expr}`
* **string类型**：文本输入框，可填写字符串或表达式 `${expr}`
* **bool类型**：开关组件

#### 表达式支持
参数值支持表达式格式 `${expr}`，其中 `expr` 为有效的数学表达式，可引用策略上下文变量（如 `cash`、`shares`、`startNav` 等）。表达式在策略执行时动态计算。

#### 保存与重置
* 点击页面底部"保存"按钮保存所有修改的参数值
* 每个策略卡片底部有"重置为默认"按钮，可将该策略的所有参数恢复为系统默认值

#### 持久化与备份
* 参数配置保存在 localStorage 的 `fund_system_config.strategyParams` 字段中
* 导出备份时会自动包含策略参数配置
* 导入备份时会自动合并策略参数配置，并兼容旧版本备份文件（无策略参数时使用默认值）
* 测试数据快照导出时会包含策略参数配置

### 搜索服务
管理系统中使用的搜索服务配置，为 AI 辅助功能提供联网查询支持。
* 列出当前系统中所有可用的搜索服务 provider，显示它们的名称、以及可配的参数。
* 搜索服务 provider 的参数配置项根据搜索服务的配置文件动态生成，支持不同搜索服务有不同的参数配置项。
* 参数输入组件根据参数类型动态生成，number 类型为文本输入框，string 类型为文本输入框，bool 类型为开关组件。
* 对于敏感参数（如 API 密钥），显示时应该 mask，使用密码输入框。
* Provider 卡片支持拖拽排序，越靠上方的 provider 优先级越高。搜索服务按优先级依次尝试，失败时自动切换到下一个 provider。
* 每个 provider 可以单独配置 enable/disable 属性，被 disable 的 provider 不会被搜索服务调用。
* 参数配置保存在 localStorage 的 `fund_system_config.searchProviders` 字段中，导入导出备份时自动包含搜索服务配置。敏感参数不参与导入和导出备份。
* 点击页面底部"保存"按钮保存所有修改的参数值，每个 provider 卡片底部有"重置为默认"按钮，可将该 provider 的参数恢复为系统默认值。
* 新增搜索服务 provider 时，系统会自动识别并加载新的搜索服务配置文件，无需修改 UI 代码。

### 依赖服务
检查系统依赖的外部服务状态。用户可以在该页面检查代理服务和搜索服务的运行状态。
* 依赖服务分为"代理服务"和"搜索服务"两类，分别显示在不同的 section 中。
* 每个依赖服务显示其名称，初始状态下不显示状态。点击"状态检查"按钮后，显示状态（正常/异常）和详情按钮。
* 状态检查功能会并行检测所有服务状态，界面显示加载状态，检测完成后更新显示每个服务的状态。
  * 代理服务使用 GET 请求测试代理连通性，验证响应内容有效性。
  * 搜索服务使用测试查询检测搜索能力，验证是否能返回结果。
* 点击"详情"按钮可查看服务的详细信息：正常时显示响应时间，异常时显示错误信息。
* 状态检查结果不持久化，每次需手动点击检查。

### 系统资源
显示系统中的资源的使用情况
#### localStorage使用情况
显示当前localStorage的使用情况，包括已使用空间、净使用空间和剩余空间。

* **进度条分段显示**：使用不同颜色区分不同类型数据的占用比例
  * 蓝色部分：FundTracker相关数据占用
  * 黄色部分：其他数据占用（可能来自浏览器扩展或其他同域应用）
  * 灰色背景：剩余可用空间
* **详细数值显示**：
  * 已使用：总占用空间（所有localStorage数据）
  * 净使用：仅FundTracker相关数据占用（蓝色高亮显示）
  * 剩余：剩余可用空间
* **数据相关性判定**：以 `services/storageKeys.ts` 中 `STORAGE_KEYS` 常量定义为准，动态判断localStorage中的key是否属于FundTracker
* **折叠式详情**：默认折叠，点击"展开详情"按钮可查看每个key的具体大小
  * FundTracker数据（蓝色背景区域）：显示相关key及其占用空间
  * 其他数据（黄色背景区域）：显示无关key及其占用空间
* **导出功能**：提供"导出 localStorage 内容"按钮，将localStorage中的所有数据导出为JSON文件，便于跨环境对比分析
* **警告提示**：当localStorage使用超过80%时，显示警告信息，建议用户清理历史数据或导出备份

#### JavaScript 内存使用情况
显示当前页面的 JavaScript 内存占用情况，帮助开发者了解内存消耗、检测潜在的内存泄漏问题。

* **JS 堆内存**：显示当前页面的 JavaScript 堆内存占用（仅 Chrome 浏览器支持）
  * 进度条可视化显示已使用/总容量比例
  * 正常状态（< 80%）：绿色进度条
  * 警告状态（≥ 80%）：红色进度条
  * 显示已使用和总容量的具体数值（MB）
* **DOM 统计**：显示当前页面的 DOM 元素信息（所有浏览器支持）
  * DOM 节点总数
  * DOM 树深度（最大层级）
* **自动刷新**：数据每 5 秒自动更新，实时监控内存变化
* **浏览器兼容性**：
  * Chrome 浏览器：显示完整的 JS 堆内存数据和进度条
  * Firefox/Safari 等其他浏览器：显示兼容性提示，DOM 统计正常显示
* **提示信息**：显示自动刷新机制说明和浏览器兼容性提示


### 数据快照
用于生成测试数据快照，方便测试人员进行数据准备。点击"生成测试数据快照"按钮后，系统会：
* 收集当前localStorage中的所有整合后数据
* 收集marketNewsService缓存数据
* 自动隐藏敏感信息（同步用户名/密码、AI API密钥）
* 导出为JSON文件，文件名格式为 `mock-data_{timestamp}.json`

## 实现细节
* 如果用户在系统配置界面点击按钮，弹出新窗口（不包括确认窗口），则自动关闭系统配置界面。
* 界面中所有的配置和动作行为都与原来的功能保持一致，只是将它们整合到了一个统一的界面中，方便用户进行管理和操作。
* 系统配置界面中的设计风格、布局和交互逻辑与主界面保持一致，确保用户体验的一致性。
