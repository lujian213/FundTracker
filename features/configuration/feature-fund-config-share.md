# 基金配置分享功能

允许用户导出基金配置并分享给其他用户导入使用，便于快速配置系统。

## 功能定位

- **目的**：在用户之间分享基金配置信息
- **数据范围**：仅包含基金的基本配置信息，不包含交易数据
- **使用场景**：用户A配置好基金后，导出配置文件分享给用户B导入

## 导出功能

- 导出系统中所有基金的配置信息
- 每个基金包含4个字段：基金代码、基金名称、常用名称、跟踪指数
- 导出文件为JSON格式，文件名使用本地时间戳

## 导入功能

- 读取JSON格式的基金配置文件
- 根据基金代码匹配系统中的基金
- 只更新系统中已存在的基金（静默跳过不存在的基金代码）
- 只更新有持仓配置的基金（不创建空配置）
- 只更新常用名称和跟踪指数两个字段，不修改其他持仓配置
- 空字符串或null值不覆盖现有值

## 界面位置

在备份管理面板中，增加"基金配置分享"区块，与"手动备份"区块并列。包含导出配置和导入配置两个按钮。

## 注意事项

1. 基金配置分享不影响其他系统数据（交易记录、大盘指数等）
2. 导入不会创建空的持仓配置，避免破坏现有数据
3. 导入时提供loading状态，避免界面卡顿
