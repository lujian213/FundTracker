# Calculator Feature

在funddetail页面上，增加一个计算器图标，位于配置仓位和交易管理按钮中间。点击打开基金份额计算器，提供从金额到基金份额的计算功能。
* 计算器中提供金额输入框，和基金份额输出框。用户输入金额后，自动计算出此金额对应的份额数，精确到小数点后2位。
* 基金份额=金额/当前基金的估值（若没有估值，则取最近的确认净值）。
* 若因为数据缺失的原因，找不到基金的估值或净值，则在基金份额输出框中显示“无法计算”，并且用红色字体表示。
* 当用户输入的金额不是一个有效的数字时，基金份额输出框显示“-”，并且用红色字体表示。
* 当用户输入的金额为负数时，基金份额输出框显示“-”，
* 金额输入框可以支持千分位输入。
