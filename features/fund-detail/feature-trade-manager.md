# Trade Manager Feature

交易管理功能允许用户管理单个基金的交易记录，包括买入、卖出、分红等交易类型的录入、查看、编辑和删除。

## 界面入口

在基金详情窗口的工具栏上，点击"交易管理"按钮，弹出交易管理窗口。

## 窗口布局

交易管理窗口分为三个区域：
1. **顶部区域**：显示基金名称、代码、当前估值，以及交易录入表单
2. **中部区域**：视图切换控件和交易记录表格
3. **底部区域**：合计行和分页控件

## 交易录入

### 输入字段

交易录入表单包含以下字段：

* **交易日期**：交易发生的日期
  * 默认值为当前日期（今天）
  * 日期输入框提供上下箭头按钮，点击可快速切换到前一天或后一天
  * 选择日期后，价格字段自动更新为该日期的历史净值

* **类型**：交易类型
  * 可选值：买入、卖出、分红
  * 默认值为"买入"
  * 切换类型时，相关字段自动重置

* **价格**：交易价格
  * 只读字段，根据交易日期自动填充
  * 价格回溯规则：
    1. 优先使用历史净值中与交易日期完全匹配的净值
    2. 若无匹配，则使用交易日期当天23:59:59之前最近的历史净值
    3. 若仍无数据，则使用当前估值

* **份额**：交易份额数量
  * **买入模式**：只读字段，根据总额自动计算
  * **卖出模式**：可输入字段，用户输入卖出份额
  * **分红模式**：固定为0，不可编辑
  * 保留两位小数，以千分位显示

* **总额**：交易总金额
  * **买入模式**：可输入字段，用户输入买入金额
  * **卖出模式**：只读字段，根据份额自动计算
  * **分红模式**：可输入字段，用户输入分红金额
  * 保留两位小数，以千分位显示

* **手续费**：交易手续费
  * 可输入字段，默认为0
  * 必须大于等于0

### 自动计算规则

* **买入交易**：
  * 份额 = (总额 - 手续费) / 价格
  * 总额 = 份额 × 价格 + 手续费

* **卖出交易**：
  * 总额 = 份额 × 价格 - 手续费
  * 份额由用户输入

* **分红交易**：
  * 份额固定为0
  * 价格固定为0
  * 手续费固定为0
  * 总额由用户输入（分红金额）

### 操作按钮

* **添加按钮**：添加新的交易记录
* **更新按钮**：更新正在编辑的交易记录（编辑模式下显示）
* **取消按钮**：取消编辑操作（编辑模式下显示）

## 交易记录表格

### 表格列

表格包含以下列：

| 列名 | 说明 | 宽度 |
|------|------|------|
| 日期 | 交易日期（yyyy-MM-dd格式） | 12% |
| 操作 | 交易类型：买入/卖出/分红/建仓 | 8% |
| 数量 | 交易份额（保留2位小数，千分位显示） | 12% |
| 价格 | 交易价格（保留4位小数） | 10% |
| 交易额 | 交易总金额（保留2位小数，千分位显示） | 18% |
| 手续费 | 交易手续费（保留2位小数，千分位显示） | 10% |
| 盈亏率 | 相对于下一交易日的盈亏百分比（保留2位小数） | 10% |
| 盈亏额 | 相对于下一交易日的盈亏金额（保留2位小数，千分位显示） | 12% |
| 操作 | 编辑和删除按钮 | 8% |

### 表格样式

* **行背景色**：
  * 买入交易：绿色背景
  * 卖出交易：红色背景
  * 建仓记录：蓝色背景
  * 分红交易：默认背景

* **排序**：
  * 默认按日期倒序排列（最新的交易在最上面）

* **分页**：
  * 每页显示10条记录
  * 底部显示"第 X / Y 页"
  * 提供上一页/下一页按钮

### 合计行

表格底部显示合计行，包含以下统计信息：

* **操作列**：显示交易总次数（买入+卖出+建仓+分红）
  * 鼠标悬停显示详细统计："买入/建仓 X 次，卖出 Y 次，分红 Z 次"

* **交易额列**：显示净投入或净回收金额
  * 净投入 = 总买入金额 + 总建仓金额 - 总卖出金额 - 总分红金额
  * 正数显示为"净投入"，负数显示为"净回收"
  * 鼠标悬停显示详细统计："总买入 X, 总卖出 Y, 总分红 Z, 净投入/净回收 W"

* **其他列**：
  * 数量列：显示所有交易份额的总和
  * 手续费列：显示所有交易手续费的总和

## 视图切换

交易管理窗口提供四种视图模式：

### 1. 普通视图

默认视图，显示所有交易记录。

* 表格显示所有交易记录
* 合计行显示完整的统计信息
* 支持编辑和删除操作

### 2. 先进先出视图

按照先进先出原则匹配买卖交易。

* 每一行代表一组匹配的买卖交易
* 显示买入日期、买入价格、卖出日期、卖出价格、份额、盈亏等信息
* 合计行不显示操作统计
* 不支持编辑和删除操作

### 3. 后进先出视图

按照后进先出原则匹配买卖交易。

* 每一行代表一组匹配的买卖交易
* 显示买入日期、买入价格、卖出日期、卖出价格、份额、盈亏等信息
* 合计行不显示操作统计
* 不支持编辑和删除操作

### 4. 错误交易视图

显示数据有错误的交易记录。

* **错误判定标准**：
  * 交易价格与历史净值不一致（精确匹配，保留4位小数）
  * 交易日无历史净值数据
  * 分红交易不检查
  * 建仓记录不检查

* **显示内容**：
  * 表格结构与普通视图一致
  * 底部有合计行和分页功能
  * 支持编辑和删除操作

* **使用场景**：
  * 快速定位和修复数据录入错误
  * 发现净值数据缺失的交易
  - 定期检查交易数据质量

## 交易编辑和删除

### 编辑功能

* 每条交易记录右侧显示"编辑"按钮（先进先出和后进先出视图除外）
* 点击编辑按钮后，顶部表单填充该交易的详细信息
* 修改后点击"更新"按钮保存
* 编辑过程中可点击"取消"按钮取消编辑

### 删除功能

* 每条交易记录右侧显示"删除"按钮（先进先出和后进先出视图除外）
* 点击删除按钮后，弹出确认对话框
* 确认后删除该交易记录

## 导入导出

### 导出功能

* 窗口顶部提供"导出"按钮
* 支持导出格式：JSON、CSV
* 导出文件包含所有交易记录
* 文件命名格式：`trades_<基金代码>_<日期时间>.json/csv`

### 导入功能

* 窗口顶部提供"导入"按钮
* 支持导入格式：JSON
* 导入前弹出确认对话框，提示用户备份现有数据
* 导入策略：覆盖现有数据
* 导入后自动刷新表格

## 批量选择

* 表格左侧提供多选框
* 表头提供全选/反选功能
* 选中记录后，底部显示选中记录的统计信息：
  * 数量合计：选中记录中买入记录的份额总和
  * 市场价值：数量合计 × 当前估值
  * 盈亏总计：选中记录的盈亏额总和

## 交互细节

### 价格回溯逻辑

当用户选择交易日期时，系统按以下顺序确定该日期的交易价格：

1. 查找历史净值中与交易日期（local YYYY-MM-DD）完全匹配的净值
2. 若无匹配，则查找交易日期当天23:59:59（local）之前最近的历史净值
3. 若仍无数据，则使用历史净值中最早的净值
4. 若历史净值数据为空，则使用窗口打开时传入的当前估值

### 空状态

* 当没有交易记录时，表格显示"暂无交易记录"提示
* 合计行不显示
* 分页控件仍显示（禁用状态）

### 数据验证

* 总额必须大于0（买入和分红）
* 份额必须大于0（卖出）
* 手续费必须大于等于0
* 交易日期不能早于基金历史净值的最早日期

## 性能优化

* 分页加载：每页只显示10条记录，避免大量数据渲染
* 虚拟滚动：表格区域使用虚拟滚动优化性能
- 价格缓存：历史净值数据缓存在内存中，避免重复请求
