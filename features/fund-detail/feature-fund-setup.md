# Fund Setup Feature

基金基本配置功能，由之前的基金仓位配置功能扩展而来。在基金基本配置功能中，可以配置基金的满仓额度、初始持仓、起始日期、初始价格，常用名称为基金设置功能。

## 界面入口
* 在基金详情窗口的工具栏上，将齿轮状的按钮的tooltip从配置仓位改成基金设置，点击后弹出基金设置窗口。

## 基金设置窗口设计及功能
窗口中可以配置以下基金基本设置信息：
* 满仓额度：用户可以输入一个数值，表示该基金的满仓额度。满仓额度必须大于0。
* 初始持仓：用户可以输入一个数值，表示该基金的初始持仓。保留两位小数，必须大于等于0。
* 起始日期：用户可以选择一个日期，表示该基金的起始日期。
* 初始价格：用户可以输入一个数值，表示该基金的初始价格。保留四位小数。默认值为该基金在起始日期的确认净值，如果该日期没有确认净值，则默认值为最近的确认净值。
* 常用名称：用户可以输入一个文本，表示该基金的常用名称。常用名称仅作为显示使用，不作为识别的主要依据。常用名称默认为空。
* 跟踪指数：用户可以输入基金的跟踪指数代码，格式为 market.code（如 2.H50036）。配置后，系统将使用跟踪指数的实时涨跌幅来计算基金估值。
* 净值类型：用户可以选择基金的净值类型，包括 T+1（正常）和 T+2（美股QDII）。默认为 T+1。
  * **T+1（正常）**：适用于国内普通基金，净值在交易日当晚更新。
  * **T+2（美股QDII）**：适用于投资美股的QDII基金，由于时差原因，净值比国内基金晚一天更新。系统会自动将盈利日期延后一天，与国内基金对齐。
  * **自动识别**：当通过OCR添加新基金时，系统会根据基金名称自动识别净值类型（必须包含"QDII"且包含"纳斯达克"、"标普"、"美股"、"美国"或"全球"关键词）。
  * **手动配置**：用户可以在基金设置窗口中手动修改净值类型。

窗口下部有取消，清除，保存3个按钮。
