# Fund Detail Enhancement Feature

为基金详情窗口增加基金的累计收益率信息，以及历史趋势图上的成本价变化曲线。

## 界面入口一：累计收益率

在基金详情窗口中，“成本价”信息的后面，加上”累计收益率”信息，显示为百分比形式（保留两位小数）。比如：累计收益率 +10.46%。正数以红色显示，负数以绿色显示。

## 基金累计收益率计算
这是金融上衡量“资金真实回报率”的标准工具，尤其适合不规则现金流（做T完美适用）。
* 把所有净现金流按时间列出：
  * 初始投入（或每笔买入）为 负数（钱流出）
  * 每笔卖出（包括T卖出的回款）为 正数（钱流入）
  * 最后一天你的剩余市值也作为正数（视为最终卖出）
* XIRR 函数，算出年化收益率。
  * 第0天：-100,000（初始投入）
  * 第1天：+101,000（卖出）
  * 第2天：-101,000（再买入）
  * 第3天：+102,010（卖出）
  * ……
  * 最后一天（比如第20天）：+ (最后卖出金额)
用 XIRR 算出来的年化利率会非常高（比如几百%），这才是你真实的资金回报率。

优点：精确，能处理不定期、不同金额的买卖，结果可直接与理财、贷款利率对比。
缺点：需要记每笔现金流日期和金额，稍微麻烦。

## XIRR 结果的解读
* 正 XIRR：你的资金实际赚了这么多（年化）。
* 负 XIRR：亏钱。

与简单收益率的区别：

简单收益率（总盈利/最大投入本金）只看首尾，忽略中途进出时间价值。
XIRR 能区分“钱在市场待了多久”，做T时间短但反复用同一笔钱，XIRR 会非常高，这符合你的直觉。

举个例子：
假设你1月1日投入10万，1月2日赚1%卖出（盈利1000），然后立即再买入，1月3日又赚1%卖出……连续做10次（每次满仓），总盈利约 10,460 元（复利1%的10次方）。

简单收益率（按最大本金）= 10,460 / 100,000 = 10.46%

XIRR（按日期）会算出 ≈ 约 1600%（因为10天内赚10%，年化夸张）—— 这个数字真实反映了你把钱反复高效利用的能力。

但注意：XIRR 假设你可以始终按照这个短周期收益率持续一整年，现实中不可能，所以它只用来比较不同投资机会的资金效率，而不是预测未来。

## 界面入口二：成本价变化曲线

在基金详情窗口的“历史趋势图”标签页中，添加成本价变化曲线。

### 曲线显示
* 在历史趋势图上绘制一条绿色曲线，代表每个日期点的成本价
* 曲线起点：从 startDate（建仓日期）开始显示，startDate 之前的日期不显示
* 曲线颜色：绿色（#22c55e）
* 曲线线宽：1.5px

### 图例显示
* 在图表左上角的 MA 值（MA5、MA10、MA20）右边显示”成本: x.xxxx”
* 悬停时显示当前悬停点的成本价，未悬停时显示最后一个数据点的成本价
* 成本价保留4位小数

### HoverTip 信息
* 在底部信息区域（时间、净值、涨跌）后面，添加”成本价”显示列
* 悬停时显示悬停点的成本价，未悬停时显示最后一个数据点的成本价
* 成本价使用绿色字体，保留4位小数

### Y轴范围
* Y轴范围同时考虑净值和成本价，确保成本价曲线在合理范围内显示
* 成本价可能为负数（如通过多次卖出”收回”成本），Y轴需能显示负数范围

### 成本价计算公式
```
成本价 = (初始成本 + 累计买入金额 - 累计卖出金额) ÷ 累计份额
```

其中：
* 初始成本 = 初始份额 × 初始价格
* 买入金额 = 价格 × 份额 + 手续费
* 卖出金额 = 价格 × 份额 - 手续费

### 计算逻辑
* startDate 之前的日期：成本价显示为 null（曲线不显示），但 startDate 之前的交易仍计入累计
* startDate 当天及之后：显示计算后的成本价
* 累计份额 ≤ 0 时：成本价显示为 null（已清仓）
* 所有交易都计入成本价计算，无论交易日期是否在 startDate 之前
