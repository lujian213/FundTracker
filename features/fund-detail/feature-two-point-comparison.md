# Two Point Comparison Feature

在基金和指数的历史趋势图上，增加两点对比功能，允许用户选择两个数据点，比较它们之间的数值变化百分比。

## 功能位置

* 模式开关：历史趋势图左上角（`top-0 left-2`），与右上角 MA 按钮形成对称布局
* 清除按钮：紧邻开关右侧
* 信息显示：按钮右侧，一行显示

## 核心交互

* 用户点击"两点对比"图标 → 模式开启 → 图标变色（蓝色高亮）
* 用户点击图表上第一个点 → 显示第一个点圆点标记（橙色）+ 信息显示（日期和数值）
* 用户点击图表上第二个点 → 显示第二个点圆点标记（紫色）+ 信息更新为两点信息 + 变化百分比
* 用户点击"清除"按钮 → 清空所有点和信息，可重新选择
* 用户再次点击"两点对比"图标 → 模式关闭 → 清空所有选择和显示

## 信息显示格式

| 状态 | 显示内容 |
|------|---------|
| 选中 0 个点 | 不显示信息 |
| 选中 1 个点 | `日期: 数值`（如 `2024-01-01: 1.2345`） |
| 选中 2 个点 | `日期: 数值 → 日期: 数值 (变化%)` |

变化百分比颜色：
* 正值（涨）：红色 `#ef4444`
* 负值（跌）：绿色 `#22c55e`

## 视觉设计

### 模式开关按钮

* 样式：与 MA 按钮风格一致，圆角、带边框、半透明背景
* 图标：`fa-ruler`（Font Awesome）
* Tooltip："两点对比"
* 开启状态：图标和边框变为主色调蓝色（`#2563eb`），背景加深

### 清除按钮

* 样式：与开关按钮风格一致
* 图标：`fa-times`
* Tooltip："清除选择"
* 显示条件：模式开启时始终显示

### 选中点标记

在 HistoryChart SVG 内渲染，叠加在趋势图上方：

* 外圈光环效果：半径 12px，半透明（30% opacity）
* 内圈实心圆点：半径 8px，白色描边 3px
* 第一个选中点：橙色 `#f97316`
* 第二个选中点：紫色 `#8b5cf6`
* `pointer-events-none`：不阻挡后续交互

## 适用范围

* 基金详情弹窗的历史趋势图
* 指数详情弹窗的历史趋势图
