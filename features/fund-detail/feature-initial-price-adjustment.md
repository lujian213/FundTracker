# Initial Price Adjustment Feature

目前由于历史原因，现有基金的初始价格是不正确的。因此需要一个根据当前正确的盈利参考值，倒推每个基金的初始价格的功能。

## 界面入口
* 在每个基金详情页的工具栏上，显示一个"调整初始价格"的扳手图标按钮，用户点击后弹出初始价格调整窗口。一个输入框，用户可以在输入框中输入正确的盈利参考值。输入框旁边有一个"保存"按钮，用户点击后根据输入的盈利参考值计算出新的初始价格，并更新到对应基金的数据中。
* 扳手图标按钮仅在以下条件同时满足时显示：
  * 初始份额 > 0
  * 系统开关中的"初始价格调整"功能已启用

## 窗口设计及功能
### 初始价格调整窗口
* 窗口标题为"调整初始价格"。
* 窗口第一排显示三项内容（三列布局，左列固定宽度，其他列上下对齐）：
  * 目前盈利：以只读输入框形式展示。取值为当前盈利。正数显示红色，负数显示绿色。输入框样式与参考盈利输入框一致（灰色背景、灰色边框）。
  * 当前价格：以只读输入框形式展示。取值为当前估值。输入框样式与参考盈利输入框一致（灰色背景、灰色边框）。
  * 目前初始价格：系统目前设置的初始价格（与基金详情页上显示的初始价格保持一致）。
* 第二排显示三项内容（布局与第一排一致）：
  * 参考盈利：输入框，用户可以在输入框中输入正确的盈利参考值。默认值设为目前盈利值。输入框中数字的颜色：正数显示红色，负数显示绿色。
  * 参考价格：输入框，用户可以在输入框中输入正确的价格参考值。默认值设为当前价格值。该价格再反推计算时，作为当前价格使用。
  * 建议初始价格：只读显示。根据用户输入的盈利参考值和价格参考值，系统计算出的建议初始价格。如果用户输入的盈利参考值和价格参考值无法计算出建议初始价格，则显示为"-"。
* 第三排居中显示一个"保存"按钮（字体小一号），将计算出来的建议初始价格保存到对应基金的初始价格数据中，并且关闭窗口。如果输入的盈利参考值和价格参考值无法计算出建议初始价格，则"保存"按钮应该处于不可点击的状态。
* 窗口右上角有一个关闭按钮，用户点击后关闭窗口而不保存任何信息。
* 当用户输入盈利参考值和价格参考值时，建议初始价格应该实时更新，显示根据用户输入的盈利参考值计算出来的建议初始价格。
* 盈利数字以两位小数的形式显示，价格数字以4位小数形式显示。

## 实现细节
* 初始价格的计算公式为目前盈利计算的反向计算。理论上，当输入与目前盈利相同的盈利参考值时，建议初始价格应该与目前初始价格相同。
* 计算公式：
  * 盈利 = (当前份额 × 当前价格) + 卖出总额 - 买入总额 - (初始份额 × 初始价格)
  * 反推：初始价格 = ((当前份额 × 当前价格) + 卖出总额 - 买入总额 - 参考盈利) / 初始份额
* 卖出总额和买入总额不包含今日的交易，但使用今日的估值进行计算（与计算基金的累计盈利一致）。
