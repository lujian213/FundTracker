# 跟踪指数估值功能

## 需求描述
当原有的基金实时估值 API 不可用时，支持通过配置跟踪指数来计算基金实时估值。

## 数据定义

| 数据 | 说明 | 格式 |
|------|------|------|
| 跟踪指数 | 基金跟踪的指数代码 | market.code（如 2.H50036）|
| 市场代码 | 指数所属市场 | 0=国证指数/深交所, 1=上交所ETF, 2=中证指数 |
| 估值计算 | 实时估值 = 前值净值 × (1 + 指数涨跌幅) | - |

## 界面入口

- 基金设置窗口 → 跟踪指数输入框（位于"常用名称"和"满仓额度"之间）

## 跟踪指数搜索功能

### 需求目的
帮助用户快速查找和配置跟踪指数，避免手动输入代码错误，提高配置效率和准确性。

### 入口
- 跟踪指数输入框内部右侧的搜索按钮（放大镜图标）

### 交互流程
1. 点击搜索按钮，弹出"搜索指数/板块"浮动窗口
2. 输入关键字（如"有色金属"）和参考涨跌幅（如"1.68"）
3. 点击"搜索"按钮
4. 系统搜索匹配的指数/板块，获取实时涨跌幅
5. 按与参考涨跌幅的接近程度排序，显示前3个最匹配结果
6. 用户点击选择某个结果
7. 浮动窗口关闭，选中的代码自动填入跟踪指数输入框

### 输入参数
| 参数 | 说明 | 示例 |
|------|------|------|
| 关键字 | 指数/板块名称关键字 | "有色金属"、"新能源" |
| 参考涨跌幅 | 用户期望的涨跌幅（用于排序匹配度）| 1.68（单位：百分比）|

### 搜索范围
- **指数**：市场指数（如中证500、沪深300等）
- **板块**：行业板块（如有色金属、新能源等）

### 结果排序规则
- 计算每个结果的涨跌幅与参考涨跌幅的绝对差值
- 按差值从小到大排序，显示前3个最接近的结果

### 搜索结果显示
| 列 | 说明 | 格式 |
|----|------|------|
| 序号 | 结果排名（1-3）| 数字 |
| 代码 | 指数/板块完整代码 | market.code（如 1.000819）|
| 名称 | 指数/板块名称 | 文本 |
| 涨跌幅 | 当前实时涨跌幅 | 百分比（红色正/绿色负）|

### 异常处理
| 场景 | 处理 |
|------|------|
| 未输入关键字 | 提示"请输入关键字" |
| 涨跌幅格式错误 | 提示"请输入有效的涨跌幅" |
| 未找到匹配结果 | 提示"未找到匹配的指数或板块" |
| 网络请求失败 | 提示"搜索失败，请检查网络连接" |
| API返回格式错误 | 提示"搜索返回数据格式错误"，支持代理降级 |
| 行情数据获取失败 | 提示"获取行情失败，请重试" |

### 技术实现要点
- 使用代理服务访问东方财富API，优先使用 raw 格式，支持 markdown 降级
- 超时控制：单个请求10秒超时
- 数据提取：从搜索结果中提取 INDEX 和 BK 类型的指数/板块
- 涨跌幅获取：批量获取所有候选结果的实时涨跌幅

## 估值获取优先级

1. 优先使用跟踪指数计算估值（如已配置）
2. 回退到原有基金估值 API

## 状态显示

| 状态 | 颜色 | 说明 |
|------|------|------|
| ok | 绿色 | 正常 |
| warning | 黄色 | 配置错误（格式无效、指数代码不存在、缺少前值净值）|
| error | 红色 | 网络错误等异常 |

## 适用场景

- ETF 联接基金：涨跌幅 ≈ 跟踪指数涨跌幅
- 原有估值 API 失效时的备用方案
