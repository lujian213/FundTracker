# 跟踪指数估值功能

## 需求描述
当原有的基金实时估值 API 不可用时，支持通过配置跟踪指数来计算基金实时估值。

## 数据定义

| 数据 | 说明 | 格式 |
|------|------|------|
| 跟踪指数 | 基金跟踪的指数代码 | market.code（如 2.H50036）|
| 市场代码 | 指数所属市场 | 0=国证指数/深交所, 1=上交所ETF, 2=中证指数 |
| 估值计算 | 实时估值 = 前值净值 × (1 + 指数涨跌幅) | - |

## 界面入口

- 基金设置窗口 → 跟踪指数输入框（位于"常用名称"和"满仓额度"之间）

## 估值获取优先级

1. 优先使用跟踪指数计算估值（如已配置）
2. 回退到原有基金估值 API

## 状态显示

| 状态 | 颜色 | 说明 |
|------|------|------|
| ok | 绿色 | 正常 |
| warning | 黄色 | 配置错误（格式无效、指数代码不存在、缺少前值净值）|
| error | 红色 | 网络错误等异常 |

## 适用场景

- ETF 联接基金：涨跌幅 ≈ 跟踪指数涨跌幅
- 原有估值 API 失效时的备用方案
