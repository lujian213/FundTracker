# 基金估值数据准确性

## 需求描述
确保基金估值和前值数据准确，避免因数据来源不稳定导致显示错误信息，影响用户判断数据的时效性和涨跌幅计算。

## 界面显示位置

| 位置 | 显示内容 |
|------|----------|
| 基金详情窗口顶部 | 实时估值（大字号）+ 涨跌幅百分比 |
| 基金详情窗口标题下方 | 前值净值 + 净值日期 |
| 基金卡片右上角 | 估值标签（当日估值/历史估值/收盘） |
| 基金卡片主数值区 | 实时估值 |
| 基金卡片底部 | 确认净值 + 净值日期 |

## 数据定义

| 数据 | 说明 | 界面呈现 |
|------|------|----------|
| 估值 | 基金实时估算净值 | 4位小数，带涨跌幅百分比 |
| 估值日期 | 估值数据对应日期 | YYYY-MM-DD 或 MM/DD 格式 |
| 前值 | 计算涨跌幅的基准净值 | 4位小数 + 日期 |
| 前值日期 | 前值净值对应日期 | MM/DD 格式 |

## 准确性规则

### 估值数据调整
当估值日期早于最近一条净值日期时：
- 使用最近一条净值作为估值数据
- 对应净值日期作为估值日期
- 界面标签从"估值"变为"历史:MM/DD"

### 前值数据调整
前值应为历史净值中，最接近估值日期（小于）的那条净值记录，前值日期为该净值记录对应的日期。

**特殊情况**：当估值日期不晚于前值日期时，需按上述规则重新确定前值。

## 用户价值
- 用户可通过标签区分实时估值与历史数据
- 确保涨跌幅计算基于正确的前值基准
- 避免因日期错乱导致的数据误导
