# 交易记录批量录入功能

提供一个批量录入界面，用户可以在该界面中一次性输入某一天多个基金的多条交易记录。每条交易记录包括：基金名称、交易类型（买入/卖出）、交易价格、金额、基金份额、手续费等信息。

### 界面入口

在基金交易明细窗口内，表格的右上方，与日期选择平齐处，增加"批量输入"按钮，点击后打开交易批量输入窗口。

### 交易批量输入窗口

* 窗口中提供日期选择组件，默认为前一个交易日（从今天往前推，第一个非周末日期）。选择不同的日期后，窗口下方的输入表格会自动刷新（恢复到初始状态，清空之前输入的数据）。用户不能选择未来的日期。
* 提供一个输入表格，表格里面提供分组，每个分组里可以增加记录。
* 表格的每一个分组代表一个在系统里有满仓份额的基金。分组里显示基金的名称。最后面增加一个"+"按钮，用户点击后可以在该分组里增加一条交易记录输入行。
* 表格里面有下列列：交易类型（买入/卖出），交易价格，基金份额，手续费，总额，操作（此列不显示表头，里面显示删除按钮）。每一行代表一条交易记录的输入。
  * 交易类型为下拉选择，选项为"买入"和"卖出"。
  * 交易价格为只读输入框。优先使用用户选择的日期对应的基金净值；若当天无净值则使用估值；若估值也没有则前推到最近的日期，使用最近可用价格。用户不能手动修改价格。精确到小数点后4位。
  * 基金份额为数字输入框，默认为0，用户输入非负数，精确到小数点后2位。如果交易类型为"卖出"，此输入框为可写；如果交易类型为"买入"，此输入框为只读，根据用户输入的总额和交易价格自动计算并显示基金份额。
  * 手续费为数字输入框，默认为0，用户输入非负数，精确到小数点后2位。
  * 总额为数字输入框，默认为0，用户输入非负数，精确到小数点后2位。如果交易类型为"买入"，此输入框为可写；如果交易类型为"卖出"，此输入框为只读，根据用户输入的基金份额和交易价格自动计算并显示总额。
  * 删除按钮：用户点击后删除该行输入。
* 表格下方提供一个总计行，包含总计买入交易条数、总计卖出交易条数、总计买入金额、总计卖出金额、总计手续费等信息。总计行会根据用户输入的交易记录自动计算并显示。
* 窗口下方提供一个"保存"按钮，用户点击后会对输入的数据进行校验，如果校验通过，则将这些交易记录保存到localStorage中对应的基金的交易记录里，并且刷新基金交易明细窗口中对应日期的交易记录列表，并且关闭窗口；如果校验不通过，则在窗口下方提示用户具体的错误信息，标注出错的输入框，并且不保存任何数据，也不关闭窗口。

### 计算逻辑

* 买入交易时，交易总额 = 基金份额 × 交易价格 + 手续费
* 卖出交易时，交易总额 = 基金份额 × 交易价格 - 手续费

### 数据校验逻辑

* 交易类型必须选择，不能为空
* 交易价格必须为正数
* 基金份额必须为正数
* 手续费必须为非负数
* 总额必须为正数
* 卖出份额超过当前持仓份额时，不阻止保存，但显示警告提示

### 价格获取规则

优先级顺序：
1. 用户选择日期的基金净值
2. 用户选择日期的基金估值
3. 前推到最近的日期，优先使用净值，其次估值

### 关闭确认

当窗口中有未保存的数据时，用户尝试关闭窗口，系统弹出确认提示："当前输入的数据尚未保存，确定要关闭吗？"
* 用户选择"确认关闭"：关闭窗口，数据丢弃
* 用户选择"取消"：保持窗口打开，数据保留

### 实现细节

* 窗口大小固定，不会因为输入内容的多少而改变
* 输入表格支持滚动，当输入的交易记录超过窗口可显示的范围（包括分组在内15条）时，用户可以通过滚动条查看和输入更多的交易记录
* 用户在输入过程中，系统会实时计算并显示总计行的信息，帮助用户了解当前输入的交易记录的整体情况
