# Index Intraday Key Times Feature

在国内指数的日内趋势图中，增加关键时间点（变盘点）的标注显示，帮助用户识别可能的趋势转折时机。

## 功能位置

* 日内趋势图（IntradayChart）
* 仅国内指数显示（如上证指数、深证成指、创业板指等）

## 关键时间点

在以下时间点显示垂直红色虚线和时间标注：

| 时间点 | 说明 |
|-------|------|
| 10:00 | 开盘后半小时 |
| 10:30 | 上午第一个关键节点 |
| 11:00 | 临近午休 |
| 13:30 | 下午开盘 |
| 14:00 | 下午第一个关键节点 |
| 14:30 | 尾盘前半小时 |

## 视觉设计

* 垂直线：红色虚线（`#ef4444`），贯穿图表高度
* 时间标注：红色文字，位于 x 轴下方，与普通时间标签区分显示
* 线宽：1px，虚线样式（`strokeDasharray="4 2"`）

## 显示逻辑

* 当数据点时间与关键时间点相差不超过 5 分钟时，在该数据点位置显示标注
* 如果数据中没有接近关键时间点的数据，则不显示该关键时间点标注
* 仅在"国内指数"的日内趋势图 tab 中显示，其他指数或基金不显示

## 适用范围

* 上证指数（sh000001）
* 深证成指（sz399001）
* 创业板指（sz399006）
* 其他国内 A 股主要指数
