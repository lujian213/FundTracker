# Index History Kline Period Feature

在指数的历史趋势图中，增加周期选择功能，支持日K、5分钟、15分钟、30分钟、60分钟的K线曲线显示。

* 在历史趋势图tab右上角添加周期选择下拉框，默认选中"日K"。
* 下拉框选项包含：日K、5分钟、15分钟、30分钟、60分钟。
* 日K模式下，保持原有功能：显示日K曲线、均线按钮（MA5/MA10/MA20/全选）、成交量柱状图。
* 分钟K模式下：显示对应周期的K线曲线、均线按钮（MA5/MA10/MA20/全选）、成交量柱状图（红涨绿跌）。
* 分钟K的时间轴显示格式为"月/日 时:分"，日K的时间轴显示格式为"月/日"。
* 净值和MA值均保留小数点后2位显示。

## 数据获取策略

分钟K线数据获取采用 JSONP 主方式 + proxyService fallback 策略：

1. **JSONP方式**：优先使用 JSONP 调用东方财富API获取数据，这是主要方式。
2. **代理方式 fallback**：如果 JSONP 调用失败（超时或错误），则尝试通过 proxyService（law-ai等代理）获取数据。
3. **失败处理**：两种方式都失败时，返回空数组，界面显示"获取K线数据失败"或"暂无K线数据"。

## 数据缓存

分钟K线数据采用内存缓存（不持久化），提升用户体验：

* 缓存 key 格式：`${symbol}-${period}`（如 `1.000001-5min`）
* 缓存限制：最大缓存20条记录，超出时删除最旧的条目
* 缓存策略：选择周期时先检查缓存，有缓存数据立即显示，同时发起请求更新数据
* 失败处理：请求失败时保留缓存数据，不替换显示

## API参数

东方财富分钟K线API参数：
* `klt`：K线周期（5/15/30/60）
* `lmt`：返回条数限制（最大支持约80个点）
