# 冒烟测试环境准备

准备一个冒烟测试的环境，为后面其他的功能测试奠定数据基础。这个环境需要包含一些基本的数据和配置，以便能够进行功能测试。

## 测试数据准备
* 增加一个新的测试用例，名字叫"testDataPrepare"。这个测试用例平时被exclude在smoke test之外，但可以在需要的时候被单独执行。它的任务步骤是：
  * 读取debug目录下的private-data.json文件，将内容构造成一个map(private-data)。如果文件不存在或者内容不合法，打印出错信息，测试失败。
  * 载入我们的备份文件（和testBed使用同一个备份文件）
  * 配置“同步管理”，用户名，密码用private-data里面的sync_user和sync_password字段的值。
  * 配置“AI配置”：点击从“模板创建”，然后，“配置名称”输入“deepseek"，“选择模板”选择“DeepSeek Chat”,点击“使用模板”。然后在“API 密钥”输入框中输入private-data里面的"api-key"字段的值，点击"更新配置“。在“配置列表”中找到"deepseek"这一行，点击激活按钮。关闭窗口。
  * 然后打开后台任务日志窗口，等到所有后台任务都显示“成功”，就把localStorge里面的内容（只包含那6个service里面用到的整合后的key，不包含legacy key)以及当时的时间戳dump到一个本地数据文件中（__mocks__目录下面，名字叫mock-data,文件名加上时间戳信息:
    yyyy-MM-dd_HH-mm-ss格式）。另外还要加上marketNewsService的缓存数据。这个文件可以被后续的测试用例用来准备测试数据。
  * 如果有后台任务显示失败，则打印出错信息，测试失败。
  * 最后在dump出来的文件中将同步配置里面的用户名和密码，以及AI配置里面的api-key都mask掉。

## 真实测试数据快照功能
在系统配置窗口增加一个“数据快照”功能，点击后右边显示一个“生成测试数据快照”按钮，点击后会把当前localStorage里面的内容（只包含那5个service：userPreferenceService, systemConfigService, appDataService, indexService, marketFundService里面用到的整合后的key，不包含legacy key)以及marketNewsService的缓存数据,和当时的时间戳dump到一个本地数据文件中（名字叫mock-data,文件名加上时间戳信息: yyyy-MM-dd_HH-mm-ss格式）。这个文件可以被后续的测试用例用来准备测试数据。文件格式和testDataPrepare测试用例里面dump的文件格式一样。这个功能主要是为了方便测试人员在需要的时候可以手动生成一份测试数据快照。

**注意** dump出来的文件中将同步配置里面的用户名和密码，以及AI配置里面的api-key都mask掉。

## 测试基座
* 编写一个测试套件，名字叫"testBedWithData"，所有需要仿真数据的smoking测试用例都放在这个测试套件下面。这个测试套件被标记为smoke test的一部分，这样在执行smoke test的时候就会执行这个测试套件里面的测试用例。
* 套件里面beforeAll要做的步骤是:(此步骤只执行一次)
  * 从__mocks__目录下面读取符合mock-data_yyyy-MM-dd_HH-mm-ss.json文件名规范的最新的文件
  * 将其中的timestamp mock为测试环境的当前时间
  * 将其中的data导入到localStorage里面

  * 验证：窗口内显示该基金的名称和代码。满仓额度，初始持仓，起始日期，初始价格等信息与基金详情窗口一致。
  * 关闭窗口。
11.2. 调整初始价格测试
  * 在基金详情窗口中，点击工具栏上的“调整初始价格”按钮，弹出“调整初始价格”窗口。
  * 验证：目前盈利，当前价格，目前初始价格字段的值与基金详情窗口一致。三个字段均为只读状态。
  * 验证：参考盈利字段的值默认为目前盈利字段的值。参考价格默认为当前价格字段的值。建议初始价格默认为当前价格字段的值。前两个字段为可写。建议初始价格字段为只读。
  * 修改参考盈利字段的值后，建议初始价格字段的值随之改变，修改参考价格字段的值后，建议初始价格字段的值随之改变。
  * 关闭窗口。
11.3. 基金份额计算器测试
  * 在基金详情窗口中，点击工具栏上的“基金份额计算器”按钮，弹出“基金份额计算器”窗口。
  * 验证：窗口内金额字段为可写，份额字段为只读。输入金额后，份额字段自动计算并显示正确的值。
  * 验证：参考价格字段显示的数值与基金详情窗口中的当前价格字段的数值一致。
  * 关闭窗口。
11.4. 虚拟交易测试
  * 在基金详情窗口中，点击工具栏上的“虚拟交易”按钮，弹出“虚拟交易”窗口。
  * 验证：窗口内显示该基金的名称和代码。现有份额字段的值与基金详情窗口中的初始份额字段的值一致。开始日期的值与基金详情窗口中的起始日期字段的值一致。现有现金字段的值是有基金详情窗口中的数值计算出来的。计算公式为：现有现金=（满仓份额-初始份额）* 建仓日期的净值（可以从历史趋势图上找到对应日期的净值）。
  * 验证：当时市场价值的值是有基金详情窗口中的数值计算出来的。计算公式为：当时市场价值=初始份额*建仓日期的净值。
  * 验证：实盘盈亏字段的值和基金详情窗口中点击“持仓盈亏”后显示的当日盈利累计字段的值一致。计算区间为建仓日期到当前日期（mock的“今天”）。
  * 验证下方四个tab中，有且应有一个tab上有星星图标显示。每个tab上都有hovertip。
  * 改变“现有份额”字段的值后，当时市场价值字段的值随之改变。改变“开始日期”字段的值后，现有现金字段和当时市场价值字段，以及实盘盈亏的值随之改变。当开始日期选择建仓日期之前的值时，当时市场价值显示为0。实盘盈亏信息消失。
  * 点击重置按钮后，所有字段的值回到初始状态。
  * 点击“开始”按钮。
  * 验证：默认选中的tab上出现大拇指图标，滚动条默认在底部。方向列上的信息有hovertip。今日提示信息上有hovertip。带有大拇指图标的tab上显示的策略总盈亏的值为所有tab中最大。
  * 验证：导出csv和导出json按钮能够正确导出当前tab的策略数据。验证：在策略数据中，日期，操作，盈亏金额，盈亏百分比等信息都是正确的。
  * 所有tab中的买入行有绿色的买入文字，卖出行有红色的卖出文字。
  * 将滚动条拉到顶部，点击其他tab，再回到原来tab，滚动条仍然在顶部。
  * 关闭“虚拟交易”窗口。
11.5. 交易管理测试
  * 在基金详情窗口中，点击工具栏上的“交易管理”按钮，弹出“交易管理”窗口。
  * 验证：窗口内显示该基金的名称和代码。当前估值字段的值与基金详情窗口中的当前估值字段的值一致。
  * 验证：交易日期默认显示mock的“今天”，价格默认显示当前估值字段的值。类型默认显示“买入”。
  * 验证：类型字段为“买入”时，总额字段可写，份额字段为只读。类型字段为“卖出”时，份额字段可写，总额字段为只读。
  * 选择类型为“买入”，输入总额和手续费后，份额字段自动计算并显示正确的值。
  * 选择类型为“卖出”，输入份额和手续费后，总额字段自动计算并显示正确的值。
  * 改变交易日期为前一天，验证价格字段的值随之改变为前一天的估值。
  * 验证：“普通视图”中表格里面的上一页，下一页按钮能够正确翻页。第一页时，上一页按钮为禁用状态。最后一页时，下一页按钮为禁用状态。
  * 验证：“普通视图”中所有交易记录的日期，类型，价格，总额，份额，手续费等信息都与mock数据中的一致。
  * 验证：所有视图中买入类型的交易记录的底色为绿色，卖出类型的交易记录的底色为红色，建仓日期的交易记录的底色为蓝色。所有交易按照日期倒序排列。所有交易的买入份额和卖出份额的总计和合计中的数字一致。计算公式为：所有买入和建仓交易的份额总和-所有卖出交易的份额总和。并且和基金详情窗口中的仓位字段的值一致。
  * 通过鼠标左击并拖动，选择“普通视图”中第一页上的前5条记录。
  * 验证：窗口下方的信息，能够正确显示被选中记录的买入记录的信息（卖出记录信息被过滤），包含商量合计和市场价值。计算公式为：数量合计=被选中记录的买入份额的总和，市场价值=被选中记录的买入份额的总和*当前价格字段的值。
  * 点击第一条记录的编辑按钮。
  * 验证：上方的编辑区域显示该记录的详细信息，包含日期，类型，价格，总额，份额，手续费等信息，并且与该记录的信息一致。
  * 验证：“先进先出”和“后进先出”视图里面没有编辑和删除按钮。
  * 关闭“交易管理”窗口。
11.6. 查看每日盈利测试
  * 在基金详情窗口中，点击工具栏上的“查看每日盈利”按钮，弹出“持仓盈亏”窗口。
  * 验证：窗口内显示该基金的名称和代码。
  * 验证：图表能够正常显示。图的x轴的起始日期为建仓日期，结束日期为mock的“今天”。鼠标在图上hover时，会有hovertip显示该点对应的日期，当日盈亏和累计盈亏值，与下方表格内的数据一致。
  * 验证：开始日期选择框的默认值为建仓日期，结束日期选择框的默认值为mock的“今天”。选择早于建仓日期的开始日期时，显示错误信息“开始日期不能早于持仓起始日期。”。当开始日期比较结束日期晚时，显示错误信息“开始日期必须早于或等于结束日期。”。
  * 点击“重置”按钮，图表和表格的数据回到初始状态，开始日期选择框的值回到建仓日期，结束日期选择框的值回到mock的“今天”。
  * 验证：图上的点的个数和表格内的数据行数一致，并且日期，当日盈利，累计盈亏等信息都与表格内的数据一致。
  * 验证：最后一条记录的累计盈利值与基金详情窗口中目前盈亏字段的值一致。
  * 修改开始和结束日期为合理值（在建仓日期和mock的“今天”之间），验证图表和表格内的数据都随之改变，并且数据一致。
  * 关闭窗口。
  * 最后关闭基金卡片窗口。
