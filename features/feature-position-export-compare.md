# Position Export and Compare Feature

## 基金持有导出文件
### 界面入口
基金持仓页面上，在放大镜图标之后增加一个导出文件按钮，点击后打开文件浏览器，将基金持仓导出成json文件。文件名格式为：`fund_position_<YYYY-MM-DD>.json`，其中`<YYYY-MM-DD>`为导出文件的日期。

### 导出文件内容
导出文件为json格式，包含所有持仓基金的持仓信息，具体字段如下：
- 基金代码
- 基金名称
- 持仓份额
- 目前估值或净值（估值优先）

## 持仓对比
### 界面入口
基金持仓页面上，在导出文件按钮之后增加一个持仓对比按钮，点击后打开打开文件浏览器，选择持仓文件。导入该文件后，系统将对比当前持仓与导入文件中的持仓信息，并打开一个新的窗口显示对比的结果。如果导入文件出错，或者导入文件的格式不正确，则提示用户导入文件失败，并说明可能的原因。
### 对比结果
对比结果包含来自基金持仓界面表格内的所有基金和来自导入文件中的所有基金。按照基金名称进行排序。每一行都代表一个基金。如果基金代码相同，但基金名称不同，统一以本地基金名称为准。每一行的内容包括：
* 基金代码
* 基金名称：已经按照上面说的对齐方式对齐可能的不同的基金名称。
* 当前持仓份额：如果当前持仓中没有该基金，则为0。否则，显示当前持仓中该基金的持仓份额。
* 当前持仓价值：如果当前持仓中没有该基金，则为0。否则，显示当前持仓中该基金的持仓价值。持仓价值的计算方式为：持仓份额 * 目前估值或净值（估值优先）。与基金持仓页面表格中的市场价值列一致。
* 导入文件持仓份额：如果导入文件中没有该基金，则为0。否则，显示导入文件中该基金的持仓份额。
* 导入文件持仓价值：如果导入文件中没有该基金，则为0。否则，显示导入文件中该基金的持仓价值。持仓价值的计算方式为：
  * 如果本地持仓中有该基金，则为：导入文件中的持仓份额 * 当前持仓中的估值或净值（估值优先）。与当前持仓价值的计算方式一致。
  * 如果本地持仓中没有该基金，则为：导入文件中的持仓份额 * 导入文件中的估值或净值（估值优先）。
* 持仓份额差异：当前持仓份额 - 导入文件中的持仓份额。
* 持仓价值差异：当前持仓价值 - 导入文件中的持仓价值。

### 对比结果窗口
对比结果窗口显示一个表格，表格有八列。
* 第一列是“基金名称”：参照基金持仓页面表格中的基金名称列。包括基金名称和基金代码，例如“华夏成长混合（000001）”。并同样带有tooltip显示完整的基金名称和代码。
* 第二列是“持仓份额”：显示当前持仓份额。格式同基金持仓页面表格中的持仓份额列。但无需显示持仓百分比信息。0则显示为“-”。
* 第三列是“持仓价值”：显示当前持仓价值。同基金持仓页面表格中的市场价值列。0则显示为“-”。
* 第四列是“对方持仓份额”：显示导入文件中该基金的持仓份额。格式同持仓份额列。
* 第五列是“对方持仓价值”：显示导入文件中该基金的持仓价值。格式同持仓价值列。
* 第六列是“份额差异”：显示持仓份额差异。格式同持仓份额列。
* 第七列是“价值差异”：显示持仓价值差异。格式同持仓价值列。
* 第八列是“比例”：显示当前持仓份额/导入文件中的持仓份额的百分比。如果当前持仓份额或导入文件中的持仓份额为0，则显示为“-”。否则，显示为一个百分比数值，表示当前持仓份额占导入文件中持仓份额的比例。保留2位小数。
* 表格有末尾总计行，对“持仓价值”，“对方持仓价值”，“价值差异”三列进行求和，对“比例”列显示“持仓价值”总计/“对方持仓价值”总计的百分比。保留2位小数。如果“持仓价值”总计或“对方持仓价值”总计为0，则“比例”列显示为“-”。
* 表格通过竖向滚动条，最多显示15条记录，超过15条记录时可以滚动查看。滚动不影响表头和总计行的显示。参照基金持仓页面表格的滚动方式。
