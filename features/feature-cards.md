# Cards Enhancement Feature

**Cards定义**：在主界面上，每个基金，大盘指数或全球指数都以一个卡片的形式展示。每个卡片上显示该基金或指数的名称，当前价格，涨跌幅等基本信息。用户可以通过点击卡片进入该基金或指数的详细信息页面。

## Card状态
* Card的状态分为三种：正常、错误和未知。以带颜色的小圆点形式展示在Card的左上角，颜色分别为绿色（正常）、红色（错误）和灰色（未知）。小圆点配置上hover提示，分别显示“正常”、“错误”和“未知”。
  * 正常状态：当基金或指数的数据成功获取并且没有错误时，Card显示为正常状态。
  * 错误状态：当基金或指数的数据获取失败或者存在错误时，Card显示为错误状态。
  * 未知状态：当基金或指数的数据获取状态不确定时，Card显示为未知状态。比如页面刚初始化，还没有成功的数据获取，或者正在尝试获取数据但尚未完成时，可以显示为未知状态。
* Card状态的更新逻辑：
  * 在页面初始化时，所有Card的状态默认为未知状态。
  * 当成功获取到基金或指数的数据后，更新对应Card的状态为正常状态。
  * 当数据获取失败或者存在错误时，更新对应Card的状态为错误状态。

这里提到的获取数据指的是从网络上获取最新的价格和涨跌幅等信息。数据获取的时机可以是在页面加载时，或者在用户点击刷新按钮时，或者在定时器触发时自动获取。而不是指从localStorage或者数据缓存中获取数据。
所以Card状态的变化主要是由数据刷新逻辑触发的。

## Card内容显示
* 遵循尽最大努力原则，Card上尽可能显示当前价格和涨跌幅等基本信息。优先级为localStorage，数据缓存，通过数据文件导入的信息。
* 每一个Card不管有没有数据存在，都应该在界面上展示出来。对于没有数据的Card，显示为未知状态，并且在价格和涨跌幅等信息的位置显示“-”或者其他占位符来表示数据缺失。如果没有名称，则用代码（必然有）来代替。
* 在卡片代码badge的右侧空白区域，显示该基金或指数的日内趋势的缩略图。这个缩略图可以是一个小的折线图，展示该基金或指数在当天的价格变化趋势。该图的内容应该和详情页上的日内趋势图保持一致。不用显示刻度。该缩略图能够随着数据的更新而更新。缩略图使用淡灰的边框。同时适用于指数和基金。

## Card添加
* 当添加一个新的Card时，不管获取数据成功与否，都应该立即在界面上展示出来。新添加的Card初始状态为未知状态，直到数据获取成功后才更新为正常状态，或者数据获取失败后更新为错误状态。
