# Profit Feature

## 单个基金盈亏计算

在FundDetails窗口上，增加盈利图标。点击打开基金盈利窗口，展示累计盈利曲线（基于持仓与价格计算）。在曲线下方，通过选择两个日期（起始和结束）来
展示该期间的盈利情况（包含基于确定净值的已实现盈亏和基于估值的未实现盈亏）。
### 核心公式
```text
* 当日盈利 = 当日累计盈利 - 前一日累计盈利
* 当日份额 = 截止到前一日的累计份额（当天交易不影响当天份额）
* 当日累计买入/卖出金额 = 截止到前一日的累计金额（当天交易不影响当天累计）
```
详细计算步骤

1. 当日份额计算
   当日份额 = 初始份额 + 截止到前一日的累计买入份额 - 截止到前一日的累计卖出份额

2. 累计盈利计算
   当日累计盈利 = 当日份额 × 当日净值 - 初始成本 - 截止到前一日的累计买入金额 + 截止到前一日的累计卖出金额

其中：
- 初始成本 = 初始份额 × 初始价格
- 累计买入金额 = Σ(买入价格 × 买入份额 + 手续费)
- 累计卖出金额 = Σ(卖出价格 × 卖出份额 - 手续费)

3. 当日盈利
   当日盈利 = 当日累计盈利 - 前一日累计盈利

交易生效时点

重要规则：**当天的交易不影响当天的份额和累计盈利，在次日才生效**

这意味着：
- 买入/卖出操作的份额变动从次日起才影响份额计算
- 买入/卖出的金额和手续费从次日起才影响累计盈利计算
- 当日盈亏仅反映净值变动带来的损益，不含当日交易的影响

示例

假设：
- 初始份额：100份，初始价格：1.0元
- 第2天：买入50份，价格1.01元，手续费0.5元，净值涨到1.02元
- 第3天：净值跌到1.00元

|日期  | 份额 | 净值 |         累计盈利         |    当日盈利    | 说明 |
|-------|------|------|--------------------------|----------------|------|
| 第1天 | 100  | 1.0  | 100×1.0 - 100×1.0 = 0    | 0（基准日）    | 无交易 |
| 第2天 | 100  | 1.02 | 100×1.02 - 100×1.0 = 2.0 | 2.0 - 0 = +2.0 | 买入不影响当天 |
| 第3天 | 150  | 1.00 | 150×1.0 - 100 - 50.5 = -0.5 | -0.5 - 2.0 = -2.5 | 昨天买入今天生效 |

注：第2天的份额仍为100份（买入次日生效），第3天份额变为150份。



* 累计盈利趋势图上，要显示横轴（日期）和纵轴（累计盈利金额），并且用hover形式展示每日对应点的日期，当日盈利金额和累计盈利金额。图中x轴的开始日期为基金的持仓起始日期。结束为当天日期。
* 盈利表格展示：在图表下方根据选择的开始和结束时间以数字形式展示每日盈亏。总共3列，第一列是“日期”，第二列是“当日净值”，第三列是“当日盈利”。使用滚动条控制一屏最多10条记录。表格下方，显示该时间段内的累计盈亏。
和，所有正数用红色代表盈利，所有负数用绿色代表亏损。所有0值，用黑色“-”表示。当用户选择不同的日期范围时，盈亏数字应动态更新。
* 开始日期必须早于结束日期（默认值为当天日期）。开始日期必须不早于持仓开始日期（默认值为持仓开始日期）。若用户选择的日期范围不合法，显示相应的错误提示。

## 整体盈亏计算
在主界面上管理按钮旁边加一个“盈利”按钮。点击后打开整体盈利窗口。类似单个基金的盈利窗口，显示累计整体盈利曲线。在曲线下方，通过选择两个日期（起始和结束）来
展示该期间的整体盈利情况。
* 整体盈亏计算逻辑：x日的累计整体盈利=基于x日的所有基金的盈利总和。
* 整体累计盈利趋势图上，要显示横轴（日期）和纵轴（累计盈利金额），并且用hover形式展示每日对应点的日期，当日整体盈利金额和累计整体盈利金额。图中x轴的开始日期为所有基金中最早的的持仓起始日期。结束为当天日期。
* 整体盈利表格展示：在图表下方根据选择的开始和结束时间以数字形式展示每日整体盈亏。总共4列，第一列是“基金名称”，第二列是“日期1整体盈利”，第三列是“日期2整体盈利”，第四列是“盈利差额”。使用滚动条控制一屏最多10条记录。表格下方，显示该时间段内的累计整体盈利差额。
所有正数用红色代表盈利，所有负数用绿色代表亏损。所有0值，用黑色“-”表示。当用户选择不同的日期范围时，整体盈亏数字应动态更新。
* 只有具有持仓开始日期且早于用户选择的日期2的基金才会被纳入整体盈亏计算和表格展示。
* 日期1必须早于日期2（默认值为当天日期）。日期1的默认值为日期2默认值的前一天。若用户选择的日期范围不合法，显示相应的错误提示。
### 简便日期选择
在盈利窗口的日期选择区域，提供一些预设的快捷选项，如“本月”、“上月”、“本年”、“去年”等。用户点击这些选项后，日期选择器会自动填充相应的日期范围，方便用户快速查看常用时间段的盈利情况。
* 当用户选择了快捷选项后，盈亏数字应动态更新，展示所选时间段的盈利情况。
* 快捷选项的日期范围定义：
  * “本月”：从上个月的最后一天到当前日期。
  * “上月”：从前个月的最后一天到上个月的最后一天。
  * “本年”：从去年的最后一天到当前日期。
  * “去年”：从前年的最后一天到去年的最后一天。
