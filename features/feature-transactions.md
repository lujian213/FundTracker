# Transactions Feature

在主界面上，增加交易按钮，位于盈利按钮旁边。点击打开基金交易窗口，展示特定日期的基金交易明细列表。
* 基金交易窗口最上方是日期选择按钮，默认值为最近前一个有交易记录的日期。如找不到前一个有交易记录的日期，则日期不可选，并在下方表格区域显示"无任何交易存在"。用户可以通过点击日期选择按钮来选择不同的日期。
* 日期选择控件能够在日历上显示出有交易记录的日期。且只能选择有交易记录的日期。用户选择日期后，表格内容应动态更新以显示该日期的交易明细。
* 下方表格显示在选定日期发生的所有交易（交易日期为选定日期）。
* 表格总共有七列，第一列是"基金名称"，第二列是"类型"，第三列是"份额"，第四列是"手续费"，第五列是"交易总额"，第六列是"交易盈亏"，第七列为多选按钮（可以控制所用行的选择与反选）。表头固定在顶部，统计行固定在底部。
* 第一列的内容（除表头）以基金名称（基金代码）方式呈现，如"招商银行（123456）"。保持内容在一行内显示，超出部分用省略号表示，并且鼠标悬停时显示完整内容。
* 表格最后为统计行，显示：总计（买入条数、卖出条数）、买入总额、卖出总额、手续费、盈亏总计。样式与"批量交易录入"窗口的总计行保持一致。
* 表中所有0值，用黑色"-"表示。所有数值以千分位表示，精确到小数点后两位。
* "交易盈亏"列显示每笔交易相对于下一个有效交易日的盈亏金额。如果无法计算盈亏金额，则显示为黑色"-"。正数显示为红色，负数显示为绿色。
* 表格使用滚动条控制一屏最多10条记录。保持表头固定在顶部，统计行固定在底部。当用户选择不同的日期时，表格内容应动态更新。
* 窗口宽度已扩大以容纳新增的"交易盈亏"列，保持表格的整体布局和样式一致。

## 交易盈亏计算方法

* **盈亏金额计算**
  * 盈亏金额 = （下一个有效交易日的净值 - 当前交易日净值）* 净交易份额 - 手续费
    * 注意：净交易份额是有符号的。
    * 如果没有下一个有效交易日，或者下一个有效交易日的净值数据不可用，则无法计算盈亏金额，显示为"-"。
* **净交易份额**
  * 如果交易为"买入"，则净交易份额等于买入份额；如果交易为"卖出"，则净交易份额等于卖出份额的相反数。
* **下一个有效交易日**
  * 下一个有效交易日是指在当前交易日之后的第一个有净值数据的日期。由于基金可能在某些日期没有净值数据，因此需要向后查找，直到找到下一个有净值数据的日期为止。
  * 如果没有找到下一个有净值数据的日期，则检查估值日期是否晚于当前交易日。如果估值日期晚于当前交易日，并且估值数据可用，则以估值日期作为下一个有效交易日，使用估值数据作为净值进行计算。
  * 如果在当前交易日之后没有任何日期有净值数据，并且估值日期也不晚于当前交易日，或者估值数据不可用，则无法计算盈亏金额。
