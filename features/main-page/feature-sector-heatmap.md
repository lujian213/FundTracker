# 板块热力图 Feature

在主界面上，增加板块热力图按钮，位于持仓按钮旁边。点击打开板块热力图窗口，展示当前市场的板块涨跌分布。
* 使用专业图表库实现热力图展示，方块大小根据板块市值决定，颜色根据涨跌幅计算。
* 热力图分为两个区域：左侧展示涨幅Top10板块，右侧展示跌幅Top10板块。
* 每个方块代表一个板块，方块大小根据该板块的总市值占总板块市值的比例进行调整。市值越大的板块，方块面积越大。
* 每个方块的颜色根据涨跌幅计算，参照主界面基金卡片的涨跌幅色彩梯度方案。涨幅区域使用红色系，跌幅区域使用绿色系，涨跌幅越大颜色越深。
* 方块内显示板块名称和涨跌幅百分比。
* 鼠标悬停在方块上时，显示详细信息提示框，包括：板块名称、涨跌幅、涨跌额、总市值、换手率、上涨家数、下跌家数、领涨股。
* 点击方块时，跳转到东方财富板块搜索页面，在新窗口打开。
* 窗口顶部有两个切换按钮："概念板块"和"行业板块"，默认选中"概念板块"。点击切换按钮时，加载对应类型的板块数据。
* 热力图上方显示区域标题和平均涨跌幅：
  - 左侧："涨幅Top10"及平均涨跌幅
  - 右侧："跌幅Top10"及平均涨跌幅
* 数据来源：从东方财富API获取板块实时数据。
* 数据更新：窗口打开时立即加载，之后定期自动刷新。刷新时保持当前选中的板块类型。
* 窗口采用懒加载方式，只有在用户点击打开时才加载相关资源，不影响主界面初始加载性能。
* 热力图区域布局应合理，左右边距对称。
* 当正在加载数据时，显示加载状态提示。
* 当数据加载失败时，显示错误信息和重试按钮。
* 窗口标题为"板块热力图"，样式与其他弹出窗口保持一致。
