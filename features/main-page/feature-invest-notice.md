# Invest Notice Feature

## 投资提示

### 界面入口
* 在主页上增加一个提示按钮，放在交易按钮后面，点击后会自动执行所有基金的虚拟交易，并打开投资提示窗口显示结果。

### 虚拟交易的执行
对所有基金使用预先配置好的交易策略，执行虚拟交易，参数使用每个基金的默认参数（即虚拟交易界面上的默认参数）。计算出每个基金在每个策略下的盈亏总金额以及今日提示（操作与否，及份额）。
以基金为单位，搜集每个基金在每个策略下的盈亏总金额，是否最佳策略（盈亏总金额最高），实盘盈亏（没有实盘盈亏则为0），以及今日提示（操作与否，及份额）。过滤掉每个策略下今日提示都是无操作的基金。
### 投资提示窗口
* 显示一个表格，表格的每一行是一个基金，第一列表头是“基金名称”，后面每一列的表头都是一个交易策略的名称,最后一列的表头是“实盘盈亏”。表格的每一列显示对应的信息：
  * 基金名称列显示基金的名称，点击后可以跳转到该基金的详情页。如果名称太长，显示时可以截断，但hover时显示完整名称。与其他地方的处理一样。
  * 每个交易策略列显示该基金在该策略下的策略总盈亏+盈亏今日提示内容（操作与否，及份额）。如果该基金在该策略下的盈亏总金额是所有策略中最高的，则在提示内容旁边加上一个大拇指图标。
    * 策略总盈亏金额为正数时显示为红色，负数时显示为绿色。格式为：“策略总盈亏：1234.56”（保留两位小数，以千分位分隔符显示）。
    * 提示内容的格式为：操作类型（买入/卖出）+空格+操作份额（保留两位小数），买入用绿色字体显示，卖出用红色字体显示。例如：“买入 1234.56”。如操作类型为“不操作”，则显示“-”，即使是最佳策略也不显示大拇指图标。
    * 今日提示上还要加上链接，能够直接跳转到相应基金的虚拟交易窗口中。
    * 策略总盈亏与今日提示内容之间可以用换行分隔显示。
  * 实盘盈亏列显示该基金的实盘盈亏金额，保留两位小数，以千分位分隔符显示。盈亏金额为正数时显示为红色，负数时显示为绿色。没有实盘盈亏的基金显示为“-”。
  * 表尾显示”总计：n条记录“，其中n为表格中基金的数量。
  * 表格由滚动条控制显示，默认显示前10条记录，如果有更多记录，用户可以通过滚动条查看剩余记录。
  * 表头和表尾固定在窗口顶部和底部，滚动表格内容时表头和表尾保持可见。
  * 在表格上方显示一个文本，内容为“以下是根据预设的交易策略计算出的投资提示，供您参考。请注意，虚拟交易的结果仅供参考，实际投资决策请谨慎考虑。”，以提醒用户虚拟交易结果的参考性质。
