# Positions Feature

在主界面上，增加持仓按钮，位于盈利按钮旁边。点击打开基金持仓窗口，展示当前的持仓的市场价值饼图。
* 基金市场价值=当前基金份额*当前基金估值（没有估值则选用最近的确认净值）。
* 饼图展示每只基金的市场价值占总持仓市场价值的比例。每个扇区代表一只基金，扇区大小根据该基金的市场价值占总持仓市场价值的比例进行调整。
* 基金名称（基金代码）以图例形式展示在饼图旁边，如“招商银行（123456）”。保持内容在一行内显示，超出部分用省略号表示，并且鼠标悬停时显示完整内容。
* 每个扇区的颜色应与图例中对应基金名称的颜色一致。鼠标悬停在扇区上时，显示该基金的市场价值和占比。
* 参与计算的基金必须是配置有持仓且持仓份额大于0的基金。
* 当没有任何基金满足持仓条件时，饼图区域显示“无持仓数据”。
* 当用户点击图例中的基金名称时，跳转到该基金的持仓详情窗口。
* 饼图上方显示持仓基金总数，以及市场总价值。总数以“n只基金”形式展示，如“5只基金”。市场总价值以千分位表示，精确到小数点后两位，并在后面加上“元”，如“1,234,567.89元”。
* 饼图下方展示持仓表格，表格总共有四列，第一列是“基金名称”，第二列是“持仓份额”，第三列是“市场价值”，第四列是“占比”。第一列的内容（除表头）以“基金名称（基金代码）”方式呈现，如“招商银行（123456）”。
保持内容在一行内显示，超出部分用省略号表示，并且鼠标悬停时显示完整内容。第四列按照该基金市场价值占总数的百分比形式展现。所有数值以千分位表示，精确到小数点后两位。当用户点击表格中的基金名称时，跳转到该基金的持仓详情窗口。
* 表格内记录根据市场价值进行降序排列。
* 表格最后显示统计行，第一列显示“总计：n条记录”，其中n为持仓基金的数量，第二列为空，第三列为所有持仓的市场价值总和，第四列显示“100%”。统计行不参与排序。
* 表格使用滚动条控制一屏最多10条记录。保持表头和表位统计行固定，不随滚动条滚动。
