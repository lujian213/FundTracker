# Job Log Feature

在主界面右上角，增加一个日志图标，位于系统配置按钮后面。点击打开后台任务日志窗口，显示后台任务的日志信息。
* 日志窗口显示后台任务的执行记录，包括任务名称、执行时间、说明等信息。
* 每个后台任务在开始执行时记录一条日志，日志内容包括任务名称、开始时间；在任务执行完成时记录一条日志，日志内容包括任务名称、完成时间、完成状态（成功/失败），以及耗时。
* 执行时间显示为本地时间，格式为yyyy/MM/dd HH:mm:ss。
* 日志信息保存在内存中，刷新页面后日志信息会丢失，不需要持久化存储。
* 日志窗口提供一个“清空日志”按钮，用户点击后会清空当前的日志信息。
* 日志只保留当天的记录，过了当天的记录会自动清除。
* 当有新的日志记录时，能够在日志窗口中自动显示。日志窗口中的滚动条如果在底部，则自动滚动到最新日志；如果不在底部，则保持当前滚动位置不变。
* 窗口固定大小，超过部分显示滚动条。窗口设计简洁，突出日志内容，方便用户查看。
