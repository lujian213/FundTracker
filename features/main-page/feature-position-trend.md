# Position Trend Feature

## 基金持有总金额趋势图

---

### 界面入口
基金持仓页面上，在市场总价值的的数值上后，加一个放大镜的图标，点击后弹出基金持有总金额趋势图。

### 数据来源
基金持有总金额趋势图的数据来自数据缓存（基金历史净值），基金持仓信息，基金交易信息，基金最新估值等数据组合而成。
- 基金A在x日的持有金额 = 基金A在x日的持仓数量 * 基金A在x日的估值或净值（估值优先，若既没有估值，也没有确认净值，则沿用前一个最近的估值或确认净值）
- 基金A在x日的持仓数量 = 基金A的初始仓位 + 基金A所有截止到在x日的买入交易的份额总和 - 基金A所有截止到在x日的卖出交易的份额总和
- 所有持仓基金在x日的持有总金额 = 所有持仓基金在x日的持有金额之和
- 所有持仓基金指的是所有在系统内有持仓配置的基金，不论其持仓数量是否为0。

### 数据展示
- 图中显示两条折线：持仓总金额曲线和净投入总额曲线。
- 持仓总金额曲线：显示所有持仓基金随日期变化的市场价值变化，横轴为时间，纵轴为持仓基金的持有总金额。
- 净投入总额曲线：显示所有持仓基金随日期变化的净投入总额变化，横轴为时间，纵轴为净投入总额。
- 净投入总额计算：净投入总额 = Σ(各基金的建仓成本 + 买入交易额 - 卖出交易额)
  - 建仓成本 = 建仓份额 * 建仓价格
  - 买入交易额 = 买入份额 * 买入价格 + 手续费
  - 卖出交易额 = 卖出份额 * 卖出价格 - 手续费
- x轴的时间范围从所有持仓基金的最早持仓时间到当天。
- 图中需显示x轴的时间刻度和y轴的净值刻度，便于用户理解数据。两条折线共用同一个Y轴，刻度范围为两条折线数据的统一最小值和最大值。
- 相邻日期如果具有相同的持有总金额或净投入总额，则在图表上显示为一个点，避免数据过于密集导致图表难以阅读。
- 图中在鼠标对应的日期位置显示一条竖直的虚线，虚线上方以hovertip方式显示日期。具体可参考日内趋势图的实现细节。
- 图的上方显示图例：持仓总金额（红色）和净投入总额（绿色）。
- 图的下方预留显示区域用于显示图中鼠标对应时间的持仓基金信息，包含四个字段：
  - 对应的时间（日期）
  - 持有总金额（精确到小数点后2位，千分位表示）
  - 净投入总额（精确到小数点后2位，千分位表示）
  - 盈利（持仓总金额 - 净投入总额，精确到小数点后2位，千分位表示，正数红色显示"盈利"，负数绿色显示"亏损"）
该区域应该预先保留位置，以避免鼠标移动时图表内容的跳动。列宽固定，避免因为数字长度的变化导致界面抖动。具体可参考日内趋势图的实现细节。

### 注意事项
- 遵循系统的显示与数据获取分离的原则，确保图表组件只负责展示数据。
- 显示的数据应该包含最新的估值，能够展现最新的持有总金额趋势。
- 图表组件需要具备良好的性能，能够流畅地展示数据变化，避免因数据量增加而导致的性能问题。
- 建仓日期只是个粗略的时间，可以认为在建仓日期之前，仓位就已经存在（并且保持不变）。
