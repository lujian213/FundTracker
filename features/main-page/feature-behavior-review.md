# Behavior Review Feature

## 行为回顾视图
在整体盈亏窗口中，增加行为回顾视图，通过点击视图切换区域的"行为回顾"按钮（大脑图标）进入。

### 行为回顾布局
* 行为回顾视图上方显示模式指示器，提示当前显示的是"整体组合"还是"单个基金"的行为分析。
* 下方显示四个卡片：行为评分、交易频率、情绪化交易、时机评分。
* 点击卡片可弹出详情窗口查看详细信息。

### 模式指示器
* 显示当前分析模式："整体组合"或"单个基金的行为分析"。
* 在单个基金模式下，显示基金名称和代码。
* 提供"重置"按钮，点击后返回整体组合模式。

### 行为评分卡片
* 显示总分（0-100分）和评级标签（优秀/良好/一般/较差）。
* 如果有历史对比数据，显示与上一期的对比变化（上升/下降/持平）。
* 评分维度：
  - **时机选择**（50分）：低位买入、高位卖出得分高，追涨杀跌得分低。
  - **情绪控制**（30分）：追涨杀跌、频繁调仓、FOMO买入会扣分。
  - **交易纪律**（20分）：定期定投、规律仓位管理得分高。
* 点击卡片弹出详情窗口，显示评分详情、历史对比、评分说明。

### 交易频率卡片
* 显示买入次数和卖出次数。
* 点击卡片弹出详情窗口，显示交易记录列表（最近50条）。
* 交易记录按日期从近到远排序，包含日期、基金、类型、份额、价格、总额。

### 情绪化交易卡片
* 显示三种情绪化交易次数：追涨杀跌、频繁调仓、FOMO买入。
* 点击卡片弹出详情窗口，显示各类情绪化交易的详细列表。
* 每条记录有hover提示，显示具体原因（如当天涨幅、买入价格等）。

### 时机评分卡片
* 显示平均时机评分。
* 显示好/一般/差三个等级的交易次数。
* 点击卡片弹出详情窗口，显示各等级的交易列表（最近50条）。

### 详情窗口功能
* 所有详情窗口使用可折叠的Section组件组织内容。
* 交易记录表格包含6列：日期、基金、类型、份额、价格、总额。
* 情绪化交易详情中，表格行有hover提示，显示具体原因。
* 提供评分规则和影响说明区域。

### 历史对比功能
* 当选择时间范围时，自动计算与该时间范围之前所有历史数据的对比。
* 对比数据在行为评分卡片和详情窗口中显示。
* 如果没有足够的历史数据，显示"数据量不足"提示。

### 单个基金分析
* 点击表格中基金行的"?"按钮，进入单个基金的行为分析模式。
* 单个基金模式下，仅分析该基金的交易记录和行为数据。
* 模式指示器显示基金名称和代码，并提供重置按钮返回整体组合模式。

### 计算方法

#### 时机评分
* 获取交易日及其前30天的净值数据。
* 计算交易日净值在30天净值中的百分位。
* **买入**：百分位<30% → 90分（低位买入），30-70% → 60分（中位买入），>70% → 30分（高位追涨）。
* **卖出**：百分位>70% → 90分（高位卖出），30-70% → 60分（中位卖出），<30% → 30分（低位杀跌）。
* 历史数据不足（<10天）或无法获取交易日净值时，返回默认60分。

#### 情绪化交易识别

**追涨杀跌**
* **追涨**：当天涨幅>3%后买入，且买入价格高于最近卖出价格（LIFO匹配）。
* **杀跌**：当天跌幅>3%后卖出，且卖出价格低于买入价格（LIFO匹配，亏损卖出）。

**频繁调仓**
* 买入后持有<7天卖出，且卖出价格低于买入价格（LIFO匹配，亏损卖出）。
* 支持部分亏损卖出的识别。

**FOMO买入**
* 当天涨幅>5%后买入。

#### 行为评分计算
* **时机选择分** = 平均时机评分 × 0.5
* **情绪控制分** = 30 - 追涨杀跌扣分 - 频繁调仓扣分 - FOMO扣分
  - 追涨杀跌：每次扣5分，最多扣15分
  - 频繁调仓：每次扣3分，最多扣9分
  - FOMO买入：每次扣3分，最多扣6分
* **交易纪律分**：定期定投（月定投或周定投）→ 20分，规律仓位管理 → 15分，否则 → 5分
* **总分** = 时机选择分 + 情绪控制分 + 交易纪律分

### 性能优化
* 使用预计算的净值索引（NavIndex）进行O(1)涨跌幅查找。
* 排序后的交易列表使用useMemo缓存，避免重复排序。
* 基金名称查找使用预计算的Map，避免O(n)查找。

### 视图切换
* 视图切换区域有四个互斥按钮：图表、日历、绩效分析、行为回顾。
* 默认选中图表视图。
