# 主界面顶部按钮区域

在主界面顶部右侧的按钮区域，提供以下五个功能按钮：

* **刷新按钮**：刷新基金和指数的实时数据及历史数据
* **日历按钮**：查看节假日、交割日和重要数据发布日信息
* **系统配置按钮**：进入系统配置界面
* **日志按钮**：查看后台任务执行日志
* **截屏按钮**：截取当前页面并复制到剪切板

按钮从左到右依次排列，位于顶部右侧按钮区。

---

## 刷新按钮

刷新按钮用于手动触发数据刷新，一次性更新所有基金和指数的实时数据及历史数据。

### 功能说明

点击刷新按钮后，系统并行执行以下四项操作：

* 刷新所有基金的实时估值数据
* 刷新所有基金的历史净值数据
* 刷新所有指数的实时数据
* 刷新所有指数的历史数据

刷新过程中按钮显示加载状态（图标旋转），刷新完成后恢复正常状态。

### 交互流程

1. 用户点击刷新按钮
2. 系统开始刷新操作，按钮显示加载状态
3. 系统并行执行四项数据刷新操作
4. 所有操作完成后，按钮恢复正常状态

### 注意事项

* 刷新过程中按钮会被禁用，防止用户重复点击
* 刷新会忽略缓存，强制从数据源获取最新数据
* 刷新过程会显示在顶部状态栏（"同步链路: 活悦"）

## 日历按钮

日历按钮用于查看各类市场日历信息，包括节假日、交割日和重要数据发布日等。

### 功能说明

点击日历按钮后，弹出月历窗口，显示本年度内的节假日、交割日和重要数据发布日信息。

### 提示功能

如果今日起三天内有事件，日历按钮上显示提示徽章（小红点），提醒用户有即将到来的事件。

### 详细功能

日历功能的详细需求请参见 [后台任务功能](../services/ai/feature-background-job.md) 的 "Calendar的显示" 章节。

## 日志按钮

日志按钮用于查看后台任务的执行日志，了解系统后台任务的运行情况。

### 功能说明

点击日志按钮后，弹出日志窗口，显示后台任务的执行记录。日志窗口显示以下信息：

* 任务名称
* 执行时间（本地时间，格式为 yyyy/MM/dd HH:mm:ss）
* 完成状态（成功/失败）
* 任务耗时

### 日志管理

* **清空功能**：用户可以点击"清空日志"按钮清空当前日志
* **自动清除**：日志只保留当天的记录，过期自动清除
* **存储方式**：日志保存在内存中，刷新页面后丢失

### 自动滚动

当有新日志记录时，日志窗口会自动显示：

* 如果滚动条在底部，自动滚动到最新日志
* 如果滚动条不在底部，保持当前滚动位置不变

### 后台任务类型

系统会记录以下后台任务的执行日志：

* 基金估值刷新
* 基金历史数据刷新
* 指数数据刷新
* 指数历史数据刷新
* 市场资讯刷新
* 推荐交易策略刷新
* Calendar节假日刷新（A股、港股、美股、新加坡）
* 基金基本信息刷新
* 重要数据刷新
* 财经快讯刷新

## 截屏按钮

截屏按钮用于截取当前应用页面并复制到剪切板，支持普通截屏和滚动截屏两种模式。

### 功能说明

系统自动检测是否需要滚动截屏：

* **普通截屏**：当页面高度 ≤ 视口高度时，截取当前屏幕内容
* **滚动截屏**：当页面高度 > 视口高度时，自动滚动页面，逐屏截图，拼接为一张完整图片

### 交互流程

**普通截屏流程：**

1. 用户点击截屏按钮
2. 浏览器弹出原生选择对话框（用户选择要捕获的标签页/窗口）
3. 用户选择并确认
4. 系统截取当前屏幕内容并复制到剪切板
5. 显示 Toast 提示："已复制到剪切板"

**滚动截屏流程：**

1. 用户点击截屏按钮
2. 系统检测到页面需要滚动截屏
3. 浏览器弹出原生选择对话框（用户选择要捕获的标签页/窗口）
4. 用户选择并确认
5. 系统隐藏所有固定元素（Header、浮动按钮、侧边栏开关等）
6. 显示进度提示窗口（"正在截取页面 1/N..."）
7. 系统自动滚动页面，逐屏截图
8. 拼接所有截图为一张完整图片
9. 复制到剪切板
10. 恢复固定元素显示和原滚动位置
11. 显示 Toast 提示："已复制到剪切板（滚动截屏 N屏）"

用户可以点击"取消"按钮中途取消滚动截屏。

### 提示信息

* **成功（普通截屏）**：`已复制到剪切板`
* **成功（滚动截屏）**：`已复制到剪切板（滚动截屏 N屏）`
* **取消**：`截图已取消`
* **失败**：`截屏失败`

### 技术实现

* 使用原生 `navigator.mediaDevices.getDisplayMedia()` API 截取真实屏幕像素
* 使用 Canvas API 拼接多张截图
* 无第三方依赖
* 最大截图数量限制为 10 屏，超过时提示用户分段截图
* 实现所见即所得，不使用重新渲染方案

### 注意事项

* 截图过程中会隐藏所有固定元素，截图结果中不包含这些元素
* 如果用户在截图过程中手动滚动页面，截图会被取消
* 截图完成后，页面滚动位置会自动恢复
* 浏览器对话框不可取消，这是浏览器安全策略的硬性限制
* 用户必须手动确认，防止恶意网站未经同意捕获屏幕

## 设计原则

* **功能聚焦**：每个按钮对应一个明确的功能，避免功能重叠
* **清晰反馈**：每个按钮操作都有明确的反馈（加载状态、Toast 提示等）
* **易用性**：按钮大小适中，便于点击
