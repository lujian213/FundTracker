# Performance Analysis Feature

## 绩效分析视图
在整体盈亏窗口中，增加绩效分析视图，通过点击视图切换区域的"绩效分析"按钮（饼图图标）进入。

### 绩效分析布局
* 绩效分析视图分为左右两部分：左侧为收益归因环形饼图，右侧为KPI指标卡片区域。
* 左侧饼图区域固定宽度280px，右侧KPI区域自适应填充剩余空间。

### 收益归因环形饼图
* 饼图显示各基金的收益占比：盈利基金用红色系表示，亏损基金用绿色系表示。
* 各基金按占比从大到小排列：盈利基金（红色）在前，亏损基金（绿色）在后。
* 每个扇区的颜色深浅根据占比变化：占比越大颜色越深，占比越小颜色越浅。
* 鼠标悬停在扇区上时，显示提示框：基金名称、代码、收益金额、收益占比。
* 点击扇区可选中该基金，右侧KPI区域显示该基金的指标。
* 再次点击已选中的扇区可取消选中，右侧KPI区域恢复显示整体组合指标。
* 选中的扇区会有轻微放大效果。
* 饼图右上角显示"重置"按钮（仅在有选中基金时显示），点击可取消选中状态，恢复显示整体组合指标。

### KPI指标卡片
* KPI区域显示5个指标卡片：年化收益率、最大回撤、收益波动率、夏普比率、卡玛比率。
* 每个卡片显示指标名称、数值和描述。
* 未选中基金时，显示整体组合的KPI指标。
* 选中某个基金后，显示该基金的KPI指标。
* 年化收益率、最大回撤、收益波动率显示为百分比格式，保留2位小数。
* 夏普比率、卡玛比率显示为数值格式，保留2位小数。
* 每个KPI指标旁边显示等级图标，鼠标悬停显示等级说明：
  - **年化收益率**：>30% 🌟(卓越), >15% 🟣(优秀), >5% 🟢(良好), >0% 🟡(一般), ≤0% 🔴(亏损)
  - **最大回撤**：<5% 🟢(低风险), <10% 🟡(中低风险), <20% 🟠(中等风险), ≥20% 🔴(高风险)
  - **收益波动率**：<15% 🟢(低风险), <25% 🟡(中低风险), <35% 🟠(中等风险), ≥35% 🔴(较高风险)
  - **夏普比率**：>3 🌟(卓越), >2 🟣(优秀), >1 🟢(良好), >0 🟡(一般), ≤0 🔴(不佳)
  - **卡玛比率**：>10 🌟(卓越), >5 🟣(优秀), >3 🟢(良好), >0 🟡(一般), ≤0 🔴(不佳)
* 持仓天数少于30天时，不显示KPI指标，显示提示信息"持仓时间过短，需至少30天持仓才能计算KPI指标"。

### 表格增强
* 绩效分析视图下，表格增加"收益占比"列，显示各基金的收益占比百分比。
* 表格中每行增加"?"按钮，点击可选中该基金并在右侧显示其KPI指标。
* 选中的基金行高亮显示。
* 表头宽度调整：基金名称列变窄，日期列显示日期而非完整标题。

### 计算方法
* **年化收益率**：使用现金流方法计算，与基金详情页的累计收益率计算逻辑一致。基于交易记录和当前市值构建现金流，使用简单收益率年化：收益率 × (365 / 投资天数)。
* **最大回撤**：
  - **整体组合**：基于虚拟净值曲线计算，从每日市值数据计算峰值到谷底的最大跌幅。
  - **单个基金**：基于基金净值曲线计算，从历史净值数据中计算峰值到谷底的最大跌幅。计算时使用当前估值数据（如有），确保回撤数据包含当日实时估值。
* **收益波动率**：从基金净值曲线计算日收益率的标准差，年化处理。
* **夏普比率**：(年化收益率 - 无风险利率) / 收益波动率，无风险利率默认为3%。
* **卡玛比率**：年化收益率 / 最大回撤。

### 视图切换
* 视图切换区域有三个互斥按钮：图表、日历、绩效分析。
* 默认选中图表视图。
* 切换到绩效分析视图时，饼图和KPI区域显示对应内容。
