# News Sidebar Feature

## 财经快讯侧边栏

---

### 数据获取方式

- 快讯数据通过后台定时任务获取，每3分钟自动刷新一次（cron: `*/3 * * * *`）。
- 数据缓存在内存中（不持久化），前端从缓存读取显示。
- 页面刷新时触发后台任务立即执行一次。
- 缓存更新时通过 `fast-news-cache-updated` 自定义事件通知前端刷新显示。

### 界面入口
- 主界面右侧边缘设置触发区域（15px宽），鼠标靠近时自动滑出侧边栏。
- 侧边栏宽度固定为420px，从页面右侧边缘滑出，覆盖整个页面右侧。
- 鼠标移出侧边栏区域后延迟300ms自动收起，鼠标重新进入可取消关闭。

### 数据来源
- 快讯数据来自东方财富快讯 API（全球直播分类）。
- API 端点：`https://np-weblist.eastmoney.com/comm/web/getFastNewsList`
- 参数：`fastColumn=102`（全球直播分类），`pageSize=20`
- 每条快讯包含：新闻ID（code）、标题、摘要、时间、重要性标识（titleColor，值为3表示重要）

### 数据展示
- 侧边栏顶部显示标题"财经快讯 · 全球直播"和快讯数量。
- 提供刷新按钮，点击触发后台任务立即执行（而非直接调用API）。
- 快讯列表使用卡片式布局，每条快讯独立卡片展示。
- 重要快讯（titleColor=3）显示红色背景和"重要"标签。
- 普通快讯使用白色背景。
- 每条快讯显示时间（HH:mm格式）、标题、摘要。
- 标题最多显示2行，摘要最多显示2行，超出截断。
- 点击快讯卡片可跳转到东方财富快讯详情页。

### 重要快讯通知

当检测到新的重要快讯（titleColor=3）时，在屏幕右侧显示通知弹窗：

- **触发条件**：后台任务检测到新的重要快讯（code不在上次记录中）
- **通知位置**：固定在屏幕右侧（right: 20px），垂直方向与"持仓"按钮下方10px位置齐平
- **显示内容**：
  - "重要"标签（红色）
  - 快讯时间
  - 标题（最多2行）
  - 摘要（最多2行）
  - 队列计数（若有多个待显示，显示"+N")
  - AI分析按钮（机器人图标）
- **显示行为**：
  - 多条重要快讯时，逐条显示
  - 每条通知显示5秒后开始淡出，3秒淡出完成，总共8秒
  - 消失后立即显示下一条（无缝衔接）
- **交互**：
  - 点击通知可跳转到快讯详情页
  - 点击AI分析按钮可打开AI分析浮窗（参见"AI快讯分析"章节）

### AI快讯分析

利用AI分析财经快讯对用户持有基金的潜在影响，提供投资参考。

#### 界面入口
- 重要快讯通知卡片上的AI分析按钮（机器人图标）
- 快讯侧边栏中每条快讯卡片右上角的AI分析按钮

#### AI分析浮窗
浮窗显示AI分析结果，支持Markdown渲染。

- **未配置AI时**：显示提示信息，引导用户去AI配置窗口进行配置和激活
- **打开窗口时**：自动使用预配置的提示词模板，向AI模型发送请求
- **窗口特性**：
  - 支持滚动查看分析结果
  - 支持拖动移动窗口位置
  - 流式输出：AI回复时实时显示内容
- **功能按钮**：
  - 复制按钮：复制分析内容到剪贴板
  - 关闭按钮：关闭浮窗
  - 重试按钮：API调用失败时提供重试选项
- **状态显示**：
  - 加载中：显示加载动画
  - 成功后：显示已连接的模型名称
  - 失败时：显示错误信息和重试按钮

#### 提示词模板
提示词模板使用以下预定义变量：
- 快讯信息：标题、摘要、时间、级别（重要/普通）
- 用户持仓基金信息：包含基金类型、板块、主要持仓等详细信息

### 滚动行为
- 侧边栏显示时，隐藏主界面滚动条，只显示侧边栏滚动条。
- 侧边栏消失后，恢复主界面滚动条。
- 滚动事件仅影响侧边栏内容，不影响主界面。

### 加载状态
- 初次加载时（缓存为空）显示加载动画（三个弹跳点）。
- API请求失败时保留原有缓存数据，不清空。

### 错误处理
- 后台任务获取快讯失败时仅记录日志，不显示错误提示，保留原有缓存数据。
- 用户可通过刷新按钮手动触发重新获取。

### 注意事项
- 滚动事件需要阻止传播到主界面，避免影响主界面滚动。
- 侧边栏关闭时需要清除延迟关闭定时器，防止内存泄漏。
- z-index层级需合理设置（触发区9997，侧边栏9998），避免遮挡其他UI。
- 重要快讯通知组件z-index为9999，高于侧边栏。
